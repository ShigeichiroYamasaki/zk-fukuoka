# 1. モデルを学習し，推論を算術化する

[応用編の全体像](./) · [次：証明生成と検証](./02-proof)

## 学習と推論を分ける

学習は，正解付きデータから重みを決める処理です．推論は，決まった重みに新しい入力を与えて答えを求める処理です．この教材でゼロ知識証明にするのは後者です．

学習用データは $x_0,x_1\in\{0,\ldots,15\}$ の全256組です．人工的な正解を「和が16以上なら1，それ以外なら0」とします．実際には和を直接調べれば済む課題ですが，学習した係数を回路へ移す過程を見るために使います．

## 整数パーセプトロンを学習する

初期値を $w=(0,0),b=0$ とし，予測を $\hat y=[w\cdot x+b\geq0]$ とします．正解との差 $\Delta=y-\hat y$ を使って，順番に次の更新を行います．

$$w_i\leftarrow w_i+\Delta x_i,\qquad b\leftarrow b+\Delta$$

配布する `train.py` は $x_0$，$x_1$ の昇順で各組を処理し，更新がなくなったところで停止します．59巡目に収束を確認し，次の係数を得ます．

$$w=(19,19),\qquad b=-296$$

したがって推論は，次の短いプログラムです．

```python
score = 19 * x[0] + 19 * x[1] - 296
label = int(score >= 0)
```

| 入力 | score | label |
| --- | ---: | ---: |
| (3, 4) | −163 | 0 |
| (8, 7) | −11 | 0 |
| (8, 8) | 8 | 1 |
| (12, 7) | 65 | 1 |

全256組で正解と一致します．ただし学習データ全体を再確認した結果であり，未知データへの汎化性能の評価ではありません．

## 有限体の中で，負数をどう扱うか

Circomのsignalは有限体の要素です．そのまま「0より小さい」と比較しても，通常の符号付き整数の意味にはなりません．ここでは入力の範囲を先に制約し，値をずらしてビットへ分解します．

入力を4ビットに制限すると，scoreの範囲は $[-296,274]$ です．そこで

$$u=\mathrm{score}+512=19x_0+19x_1+216$$

と置くと，$216\leq u\leq786<1024$ になります．$u$ を10ビットで表したとき，最上位ビットが1であることと $\mathrm{score}\geq0$ が同値になります．

$$u=\sum_{i=0}^{9}2^i b_i,\quad b_i(b_i-1)=0,\quad y=b_9$$

入力にも同じ仕組みで4ビットの再構成制約を課します．ビットの計算をウィットネス生成処理だけに任せず，**0か1であることと，元の値へ再構成できることを回路で制約する**のが重要です．この小さな値域では体の法を跨がず，整数としての意味を保てます．

## 公開するものを限定する

回路のmainには `public` 入力を指定しません．`x[2]` は非公開，唯一の出力 `label` は公開です．scoreや各ビットをmainの出力に追加してはいけません．モデルの係数は公開の回路定数なので，推論に使うモデルは検証鍵に結び付きます．

モデルを再学習して係数を変更した場合は，回路の定数・値域の計算・テストを更新し，再コンパイルとGroth16の回路固有の鍵生成を行います．検証者は承認したモデルの検証鍵を使います．証明者が渡した未知の検証鍵を無条件に採用しません．

この例は最初から整数で学習しているので，浮動小数点モデルの丸め誤差はありません．実際のニューラルネットワークへ進むときは，固定小数点のスケール，負数，丸め，飽和，活性化関数を明示し，「どの数値計算を証明しているか」を定める必要があります．
