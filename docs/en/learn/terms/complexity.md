# Polynomial time, circuit size and depth, P and NC

[Session 4](../session-04) · [Term guide](./) · [Prerequisites](../foundations)

Updated: September 27, 2026

## Measure the input encoding

Complexity is normally measured against input bit length. Writing an integer $N$ takes about $\log_2 N$ bits. Counting to $N$ may therefore take exponentially many steps in its bit length $n$.

Polynomial time bounds execution by a fixed-degree polynomial such as $n^2$ or $n^5$. It is a theoretical efficiency criterion, not a promise of practical speed at every input size.

## Size versus depth

Size counts gates; depth counts the longest chain of dependent gates. With binary addition gates:

| Sum eight inputs | Gates | Depth |
| --- | --- | --- |
| Left-to-right chain | 7 | 7 |
| Balanced pairwise tree | 7 | 3 |

The work is unchanged but dependency depth differs. For $n$ inputs, balanced addition has $O(\log n)$ depth.

## Families and uniformity

A circuit family $C_1,C_2,\dots$ handles different input lengths. Uniformity requires that circuits can be generated by a specified computational procedure, rather than chosen arbitrarily for each length.

P is deterministic polynomial time, equivalently polynomial-time-uniform polynomial-size Boolean circuit families. Without uniformity, polynomial-size circuit families define P/poly.

Here NC uses logspace-uniform polynomial-size bounded-fan-in circuits with depth $O((\log n)^k)$ for a fixed constant $k$. Uniformity conventions vary; read the definition being used. NC does not restrict depth to only $O(\log n)$.

## Connection and self-check

These quantities help estimate representation cost. They do not imply “R1CS is always fast for NC” or “AIR is required for P.” Memory, constants and gate choices also matter.

Why does balancing eight-input addition not reduce gate count?

::: details Answer
Each binary addition reduces the number of remaining values by one. Going from eight to one requires seven additions; the arrangement changes which operations can run concurrently.
:::
