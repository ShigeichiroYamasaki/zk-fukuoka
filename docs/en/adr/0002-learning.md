# ADR-0002 · Learn through a syllabus and experiments

- Date: 2026-09-24
- Status: proposed

## Context

Learners arrive with different mathematical and programming backgrounds. A collection of disconnected talks can make it hard to identify the next step.

## Proposal

Make the syllabus the entry point. Follow four stages: foundations, proof concepts, circuits, and a shared project. Each stage defines an outcome and a deliverable. Collect feedback after exercises and revise the next cycle.

## Alternatives

Standalone talks are easy to attend but provide less continuity. A research-paper-only format serves experienced participants but raises the entry barrier.

## Consequences and review

We need exercise maintainers and peer reviewers. Adjust prerequisites and scope after observing the first learning cycle. Dates and tools remain undecided.
