# # Session 1 exercise: statements and verification

[Session 1: What is a proof?](../learn/session-01) · [Exercises index](./)

Check the relationship between a public statement $x\in L$ and its witness.

### Try it

Let $L$ contain claims that two graphs with the same number of edges are isomorphic. Choose a small graph pair and state the condition on a vertex permutation $\pi$ that makes it a witness, using adjacency. Also verify that the map is a bijection.

### Check

The statement is a property of the public graphs; the witness is a vertex correspondence proving isomorphism. Verify that adjacency is preserved for every pair of vertices.
