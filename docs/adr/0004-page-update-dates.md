# ADR-0004 · 全ページへの最終更新日の表示

- 日付：2026-10-12
- ステータス：サイトに実装

## 背景

教材や補助資料が増えるにつれて，各ページがいつ更新されたかを読者が確認しにくくなっています。ページごとに日付を手入力すると，本文の修正時に更新漏れが起きたり，実際には変更していないページの日付まで不正確になったりします。

## 決定

VitePress の最終更新表示を有効にし，Git の各ページの最終変更日時を全ページに表示します。日付は日本語ページでは「最終更新」，英語ページでは「Last updated」とし，ページ内容を変更したコミットに基づいて自動的に変わるようにします。GitHub Pages のビルドでは履歴を取得するため，チェックアウトを full history にします。

## 代替案

各 Markdown 文書に更新日を手入力する方法は単純ですが，記載漏れや日付の不整合を防ぎにくいため採用しません。ビルド日をすべてのページに表示する方法も，変更されていないページまで更新されたように見えるため採用しません。

## 影響と見直し

ページの更新日は Git の履歴に依存します。Git 履歴を含まない環境では日付を正しく計算できないため，公開ビルドでは履歴取得を維持します。ページの作成・更新がコミットされた後に表示日が更新されます。
