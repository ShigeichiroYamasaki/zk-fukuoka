# ADR-0001 · VitePress による日英ドキュメント

- 日付：2026-09-24
- ステータス：サイトに実装済み／コミュニティ合意待ち

## 背景

親しみやすいトップページと、更新しやすい教材・ホワイトペーパー・意思決定記録が必要です。日本語と英語の両方からアクセスできる構成にします。

## 決定内容

単一の GitHub リポジトリで Markdown と VitePress を管理し、Actions から GitHub Pages に静的サイトを公開します。日本語はルート、英語は `/en/` に配置します。言語タブは閲覧中の文書を維持して切り替えます。

## 代替案

CMS はブラウザーから編集しやすい一方で運用対象が増えます。独自アプリは自由度が高い一方、ドキュメント機能の保守負担が増えます。

## 影響

変更を差分としてレビューできます。貢献には基本的な Git の知識が必要です。翻訳は原文と一緒にレビューします。公開先ごとに Pages のベースパスを設定します。このサイトは `/zk-fukuoka/` を使用します。
