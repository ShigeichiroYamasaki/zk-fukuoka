# ADR-0005 · プロジェクト共通の用語・訳語

- 日付：2026-10-12
- 最終更新：2026年10月18日
- ステータス：提案・サイト反映済み／コミュニティ合意待ち

## 背景

授業資料，演習，補助教材，応用編を日英で作成する中で，同じ暗号学・計算量理論の概念に複数の日本語訳が使われると，ページ間のつながりが見えにくくなります。一方，論理学などで役割の異なる用語を機械的に一つの訳語へまとめると，かえって意味が曖昧になります。

## 決定内容

以下をプロジェクト共通の優先訳語とします。本文では初出時に必要に応じて英語も併記し，数式・定義の意味を保つために訳語だけでは区別できない場合は短い説明を添えます。

| English | 優先する日本語表記 | 用法 |
| --- | --- | --- |
| proposition | 命題 | 真偽を評価する論理・数学上の対象を指す。 |
| assertion | 言明 | ある命題について，それが真か偽かを述べる行為またはその表現を指す。命題そのものと混同しない。 |
| claim | 主張 | 説明文で提示する主張を指す。形式論理上の対象を指す場合は proposition／命題を使う。 |
| witness | ウィットネス | 関係 $R(x,w)$ などで，命題が成り立つことを示すために提示される値 $w$ を指す。「証人」は使わない。 |
| extractor | 抽出器 | 証明者の実行からウィットネスを取り出すアルゴリズムを指す。「抽出者」は使わない。 |
| knowledge extraction | 知識の抽出 | 抽出器によってウィットネスを取り出す性質・過程を指す。 |
| knowledge soundness | 知識の健全性 | 受理される証明とウィットネスの知識との関係を表す性質を指す。 |
| completeness | 完全性 | 条件を満たす正直な証明者の証明が受理される性質を指す。 |
| soundness | 健全性 | 偽の命題や無効な証明を受理する確率を抑える性質を指す。 |
| soundness error | 健全性誤差 | 不正な証明が受理される確率の上界を指す。 |
| soundness amplification | 健全性増幅 | プロトコルの反復などにより健全性誤差を小さくすることを指す。 |
| simulator paradigm | シミュレータパラダイム | 実際の証明者との対話と，秘密を知らずに生成するシミュレーションの識別可能性を比較するゼロ知識性の考え方を指す。 |
| simulator | シミュレータ | ゼロ知識性の定義で，秘密を知らずに対話記録を生成するアルゴリズムを指す。 |
| trusted setup | トラステッドセットアップ | 秘密のトラップドアを適切に生成・管理する初期設定を指す。「信頼設定」は使わない。 |
| folding | フォールディング | 多項式や証明対象のインスタンスを段階的にまとめる操作を指す。「折り畳み」「畳み込み」はこの意味では使わない。 |
| polynomial divisibility | 多項式の整除性 | 多項式が別の多項式で割り切れる関係を指す。「割り切れ性」は使わない。 |
| probability distribution | 確率分布 | 確率変数が各値を取る確率を定めるものを指す。確率的な意味を表す箇所では「分布」だけに省略しない。 |
| hash function | ハッシュ関数 | 任意長の入力を固定長の値へ写す一般的な関数を指す。暗号用途で使うものは「暗号学的ハッシュ関数」と呼ぶ。 |
| cryptographic hash function | 暗号学的ハッシュ関数 | 衝突耐性などの暗号学的性質を期待して暗号プロトコルで使うハッシュ関数を指す。「ハッシュ関数」とだけ書かず，この名称を使う。 |
| view | ビュー | ゼロ知識性の議論では，検証者がプロトコル中に得る情報（自身の入力・乱数と受け取ったメッセージなど）の全体を指す。日本語本文では「ビュー」と表記する。 |
| prover | 証明者 | 証明を生成する側を指す。 |
| verifier | 検証者 | 証明を検査する側を指す。 |
| commitment | コミットメント | 値を後から変更できないよう拘束し，方式に応じて内容を隠す暗号学的構成を指す。 |

## 運用

新しい訳語を追加する場合や既存の訳語を変える場合は，まずこのADRを更新し，日本語・英語の用法をそろえます。その後，授業資料，図表，補助教材，演習，応用編を検索し，本文と図中の表記を同じ変更で修正します。原語の意味や方式ごとの定義が異なる場合は，単語だけを一括置換せず，用例の文脈を確認します。

## 影響と見直し

共通の優先訳語により，ページ間の表記ゆれを減らし，初学者が同じ概念を追いやすくします。専門分野でより適切な訳語が定着した場合や，既存の訳語が誤解を生むことが分かった場合は，理由と影響範囲を示して本ADRを改訂します。
