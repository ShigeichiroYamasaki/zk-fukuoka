# ADR-0005 · プロジェクト共通の用語・訳語

- 日付：2026-10-12
- 最終更新：2026年10月20日
- ステータス：提案・サイト反映済み／コミュニティ合意待ち

## 背景

授業資料，演習，補助教材，応用編を日英で作成する中で，同じ暗号学・計算量理論の概念に複数の日本語訳が使われると，ページ間のつながりが見えにくくなります。一方，論理学などで役割の異なる用語を機械的に一つの訳語へまとめると，かえって意味が曖昧になります。

## 決定内容

以下をプロジェクト共通の優先訳語とします。本文では初出時に必要に応じて英語も併記し，数式・定義の意味を保つために訳語だけでは区別できない場合は短い説明を添えます。

| English | 優先する日本語表記 | 用法 |
| --- | --- | --- |
| proposition | 命題 | 真偽を評価する論理・数学上の対象を指す。 |
| assertion | 言明 | ある命題について，それが真か偽かを述べる行為またはその表現を指す。命題そのものと混同しない。 |
| claim | 主張 | 説明文で提示する主張を指す。形式論理上の対象を指す場合は proposition／命題を使う。 |
| witness | ウィットネス | 関係 $R(x,w)$ などで，命題が成り立つことを示すために提示される値 $w$ を指す。「証人」は使わない。 |
| extractor | 抽出器 | 証明者の実行からウィットネスを取り出すアルゴリズムを指す。「抽出者」は使わない。 |
| knowledge extraction | 知識の抽出 | 抽出器によってウィットネスを取り出す性質・過程を指す。 |
| knowledge soundness | 知識の健全性 | 受理される証明とウィットネスの知識との関係を表す性質を指す。 |
| completeness | 完全性 | 条件を満たす正直な証明者の証明が受理される性質を指す。 |
| soundness | 健全性 | 偽の命題や無効な証明を受理する確率を抑える性質を指す。 |
| soundness error | 健全性誤差 | 不正な証明が受理される確率の上界を指す。 |
| soundness amplification | 健全性増幅 | プロトコルの反復などにより健全性誤差を小さくすることを指す。 |
| simulator paradigm | シミュレータパラダイム | 実際の証明者との対話と，秘密を知らずに生成するシミュレーションの識別可能性を比較するゼロ知識性の考え方を指す。 |
| simulator | シミュレータ | ゼロ知識性の定義で，秘密を知らずに対話記録を生成するアルゴリズムを指す。 |
| trusted setup | トラステッドセットアップ | 秘密のトラップドアを適切に生成・管理する初期設定を指す。「信頼設定」は使わない。 |
| folding | フォールディング | 多項式や証明対象のインスタンスを段階的にまとめる操作を指す。「折り畳み」「畳み込み」はこの意味では使わない。 |
| polynomial divisibility | 多項式の整除性 | 多項式が別の多項式で割り切れる関係を指す。「割り切れ性」は使わない。 |
| probability distribution | 確率分布 | 確率変数が各値を取る確率を定めるものを指す。確率的な意味を表す箇所では「分布」だけに省略しない。 |
| negligible function | 無視可能関数 | 任意の正の多項式 $p(n)$ に対し，十分大きな $n$ で $1/p(n)$ より小さくなる非負関数を指す。「無視できる関数」は用語名として使わない。確率・距離・差については「無視可能である」と表記する。 |
| hash function | ハッシュ関数 | 任意長の入力を固定長の値へ写す一般的な関数を指す。暗号用途で使うものは「暗号学的ハッシュ関数」と呼ぶ。 |
| cryptographic hash function | 暗号学的ハッシュ関数 | 衝突耐性などの暗号学的性質を期待して暗号プロトコルで使うハッシュ関数を指す。「ハッシュ関数」とだけ書かず，この名称を使う。 |
| view | ビュー | ゼロ知識性の議論では，検証者がプロトコル中に得る情報（自身の入力・乱数と受け取ったメッセージなど）の全体を指す。日本語本文では「ビュー」と表記する。 |
| prover | 証明者 | 証明を生成する側を指す。 |
| verifier | 検証者 | 証明を検査する側を指す。 |
| commitment | コミットメント | 値を後から変更できないよう拘束し，方式に応じて内容を隠す暗号学的構成を指す。 |
| probability space | 確率空間 | 試行の標本空間，その上で確率を割り当てる事象の集合，確率測度の三つ組を指す。 |
| probability measure | 確率測度 | 標本空間上の事象に確率を割り当てる関数を指す。 |
| experiment / trial | 確率実験／試行 | 結果が確率的に決まる手続き，またはその一回の実行を指す。 |
| sample space | 標本空間 | 確率実験で起こりうる結果を集めた集合を指す。 |
| event | 事象 | 標本空間の部分集合であり，その事象が起こる確率を考える対象を指す。 |
| random variable | 確率変数 | 標本空間の結果を数値などの値へ対応づける関数を指す。 |
| probability distribution | 確率分布 | 確率変数の値や事象に確率を割り当てる法則を指す。「分布」だけに省略しない。確率質量関数・確率密度関数・累積分布関数は，確率分布を表す異なる関数である。 |
| probability mass function (PMF) | 確率質量関数 | 離散確率変数が各値を取る確率を表す関数を指す。 |
| probability density function (PDF) | 確率密度関数 | 連続確率変数の確率分布を密度として表す関数を指す。密度の値そのものは一点の確率ではない。 |
| cumulative distribution function (CDF) | 累積分布関数 | 実数値確率変数について $F(x)=\Pr[X\le x]$ と定める関数を指す。「確率分布関数」と混同しない。 |
| joint distribution | 同時確率分布 | 複数の確率変数の組が同時に取る値に確率を割り当てる法則を指す。 |
| marginal distribution | 周辺確率分布 | 同時確率分布から他の変数を周辺化して得る，一つまたは一部の変数の確率分布を指す。 |
| conditional probability | 条件付き確率 | ある事象が起きたという条件のもとで，別の事象が起こる確率を指す。 |
| multiplication rule / chain rule | 積の公式／連鎖律 | 同時に起こる事象の確率を条件付き確率の積に分解する公式を指す。プロトコルの乱数選択順序や反復確率を扱うときは，条件付けを明記する。 |
| law of total probability | 全確率の法則 | 標本空間を分割する事象ごとの条件付き確率を重み付きで足し，全体の確率を求める法則を指す。 |
| Bayes' theorem | ベイズの定理 | 観測された結果を条件として，原因や仮説の条件付き確率を求める関係式を指す。 |
| independence | 独立性 | 一方の事象や確率変数について知っても，他方の確率法則が変わらない関係を指す。複数の対象では，ペアごとの独立性と相互独立性を区別する。 |
| expectation | 期待値 | 確率変数の値をその確率で重み付けした平均を指す。期待値の線形性は，確率変数間の独立性を必要としない。 |
| variance | 分散 | 確率変数が期待値の周りにどれだけ広がるかを表す期待値 $\mathbb{E}[(X-\mathbb{E}[X])^2]$ を指す。 |
| Bernoulli random variable | ベルヌーイ確率変数 | 0または1を取り，1となる確率で成功などの事象を表す確率変数を指す。 |
| indicator random variable | 指示確率変数 | ある事象が起きたとき1，起きなかったとき0を取る確率変数を指す。 |
| union bound | 和事象の上界 | 事象の和集合が起こる確率を，各事象の確率の和で上から抑える不等式を指す。事象間の独立性を必要としない。 |
| Markov's inequality | マルコフの不等式 | 非負確率変数の期待値から，上側の裾確率を評価する不等式を指す。 |
| Chebyshev's inequality | チェビシェフの不等式 | 分散から期待値の周りの偏差確率を評価する不等式を指す。 |
| Hoeffding's inequality | Hoeffdingの不等式 | 独立で有界な確率変数の和または平均が期待値から加法的にずれる確率を評価する不等式を指す。 |
| Chernoff bound | チェルノフ上界 | 独立なベルヌーイ確率変数の和などについて，期待値からの相対的なずれを評価する上界を指す。 |
| birthday bound | 誕生日バウンド | 一様な有限集合から複数回値を選ぶとき，少なくとも一度衝突する確率を評価する上界を指す。 |
| distinguisher | 識別器 | 観測記録を入力として受け取り，その出所などを予測する確率的手続きを指す。 |
| distinguishing advantage | 識別能力（出力確率差） | 二つの確率的実験で識別器が1を出す確率の差の絶対値を指す。統計的仮説検定における「有意差」とは異なる。 |
| output-probability difference | 出力確率差 | 二つの実験で，指定した識別器が所定の出力を返す確率の差を指す。本ADRでは識別能力の定義に用いる。 |
| computational indistinguishability | 計算量的識別不能性 | 確率的多項式時間のすべての識別器について，二つの実験に対する識別能力が安全性パラメータに対して無視可能である性質を指す。 |
| total variation distance | 全変動距離 | 離散確率分布間の距離で，有限標本空間では最大識別能力に等しい。統計距離一般と区別し，対象が連続分布などの場合は適用する距離の定義を明記する。 |
| almost-sure equality | ほとんど確実な等しさ | 二つの確率変数が確率1で等しいことを指す。すべての標本点で等しいことや，同じ確率分布を持つことと区別する。 |
| equality in distribution | 確率分布の等しさ（同分布） | 確率変数の確率分布が等しいことを指す。標本点ごとの値の一致を意味しない。 |
| chi-square test | χ²検定 | 観測度数と帰無仮説のもとでの期待度数を比較する統計的検定を指す。実験上の特定の差を調べるもので，識別器すべてに対する識別不能性の証明ではない。 |
| p-value | p値 | 帰無仮説のもとで，観測値以上に極端な検定統計量が得られる確率を指す。帰無仮説が正しい確率とは解釈しない。 |
| statistical significance | 統計的有意性 | あらかじめ定めた統計的検定の基準に基づく判断を指す。暗号学的な識別能力や出力確率差と混同しない。 |
| confidence level | 信頼水準 | 標本抽出を繰り返すとき，手順で構成した区間が真の値を含む割合についての保証を指す。未知の母数に確率を割り当てる表現ではない。 |
| security parameter | 安全性パラメータ | 暗号方式の入力長や計算資源，確率的保証を漸近的に評価するための整数パラメータを指す。 |
| perfect zero-knowledge | 完全ゼロ知識 | 実際のビューとシミュレータが生成する記録の確率分布が完全に一致するゼロ知識性を指す。 |
| statistical zero-knowledge | 統計的ゼロ知識 | 実際のビューとシミュレータの記録の全変動距離など，所定の統計距離が無視可能であるゼロ知識性を指す。 |
| computational zero-knowledge | 計算量的ゼロ知識 | すべての確率的多項式時間識別器に対する識別能力が無視可能であるゼロ知識性を指す。 |

## 運用

新しい訳語を追加する場合や既存の訳語を変える場合は，まずこのADRを更新し，日本語・英語の用法をそろえます。その後，授業資料，図表，補助教材，演習，応用編を検索し，本文と図中の表記を同じ変更で修正します。原語の意味や方式ごとの定義が異なる場合は，単語だけを一括置換せず，用例の文脈を確認します。

## 影響と見直し

共通の優先訳語により，ページ間の表記ゆれを減らし，初学者が同じ概念を追いやすくします。専門分野でより適切な訳語が定着した場合や，既存の訳語が誤解を生むことが分かった場合は，理由と影響範囲を示して本ADRを改訂します。
