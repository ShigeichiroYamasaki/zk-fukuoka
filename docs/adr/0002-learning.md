# ADR-0002 · シラバスを入口とする体験型学習

- 日付：2026-09-24
- ステータス：提案

## 背景

参加者の数学・プログラミング経験はさまざまです。単発の講演を並べるだけでは、次に何を学ぶべきか分かりにくくなります。

## 提案

教育コンテンツの入口をシラバスとし、基礎・証明の理解・回路・共同制作の4段階を設けます。各段階に到達目標と成果物を定めます。演習後のフィードバックを集め、次の学習サイクルに反映します。

## 代替案

単発講演は参加しやすい一方、学びの連続性が弱くなります。論文輪読だけの形式は経験者に有用ですが、初学者の参入障壁が高くなります。

## 影響と見直し

演習の整備と相互レビューの担当が必要です。最初の学習サイクルで得られた知見をもとに、前提知識と範囲を調整します。開催日程とツールは未定です。
