# シラバス

ゼロ知識証明を「説明できる」から「小さく実装できる」へ。教育コンテンツはこのシラバスを入口に、順番に学べる構成にします。

::: info カリキュラム草案 · v0.1
設立準備段階の提案です。開催日程・講師・会場・採用ツールは未定。学習者のフィードバックをもとに調整します。現時点で公開している教材は「01 · 基礎をつかむ」の導入です。
:::

## 対象と準備

- ゼロ知識証明に興味がある学生・エンジニア・研究者。
- プログラミングの基本（変数・関数・テスト）が分かることを想定。暗号の専門知識は問いません。
- Git の基本操作と開発環境を準備。数学は必要になったところで学び直します。

## 学び方

各回は「事前に読む → 一緒に考える → 手を動かす → 気づきを共有する」の順で進めます。時間と回数は参加者と相談して決めます。修了認定制度は未定です。

## 01 · 基礎をつかむ {#foundations}

**目標：** 公開する情報と秘密にする情報を区別し、有限体での計算を説明できる。

- 剰余算術、素数、有限体、多項式の基礎。
- ハッシュとコミットメントの役割、隠蔽性と束縛性。
- 演習：小さな素数を使い、和・積・逆元を求める。
- 成果物：計算例と、「何を隠して何を証明したいか」を記述したメモ。

[導入教材を読む →](./foundations)

## 02 · 証明を理解する {#proofs}

**目標：** 完全性・健全性・ゼロ知識性の違いを、自分の言葉で説明できる。

- 証明者と検証者、主張と witness。
- 対話型証明の考え方と非対話化の概要。
- 演習：例題で検証者が知る情報と知る必要がない情報を整理する。
- 成果物：プロトコルの流れ図と、成立に必要な仮定。

教材は準備予定です。

## 03 · 回路をつくる {#circuits}

**目標：** 主張を制約として表し、正しい入力と不正な入力を検証できる。

- 公開入力・秘密入力、回路、制約の不足。
- 証明生成と検証の流れ、セットアップと信頼の仮定。
- 演習：選定した学習用ツールで小さな制約を書き、想定外の入力でもテストする。
- 成果物：回路、再現手順、正常系・異常系のテスト。

教材・ツール選定は準備予定です。選定理由は ADR に記録します。

## 04 · つくって、共有する {#project}

**目標：** 限定した用途の試作を作り、できることと限界を伝えられる。

- アイデア例：秘密値の範囲証明、集合への所属証明。
- 演習：小チームで設計・試作し、お互いにレビューする。
- 成果物：ソースコード、README、脅威と制約のメモ、デモ。
- 振り返り：再現性、制約の妥当性、情報漏洩の可能性、説明の分かりやすさ。

教材は準備予定です。試作は学習用であり、実運用向けの安全性を保証しません。
