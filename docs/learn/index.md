## 設計方針

道具(数学的基礎)から積み上げるのではなく，**目的・動機を先に立ててから道具を揃える**三幕構成を採る．

- **幕I(目的と動機)**:なぜこの技術が必要か，何を達成したいのかを定義する
- **幕II(道具立て)**:幕Iで立てた課題を解くための数学・情報理論・暗号理論の言語を揃える
- **幕III(統合)**:実際のプロトコル(Groth16 / PLONK / STARK)が幕Iの課題にどう答えているかを，成り立ちと発展の方向込みで読む

幕Iと幕IIIが対応する設計とすることで，幕IIの技術習得期間中も目的意識が切れないようにする．

## 幕I:目的と動機(なぜこの技術が必要か)— 第1〜2回 {#act-1}

### 第1回:証明とは何か — 対話型証明の背景と形式化 {#session-1}

[第1回の講義本文を読む →](./session-01)

- NPのウィットネスを直接渡す検証方法について，全開示と非対話性を問い直す．NPの定義自体が全ビットの読み取りや1回の走査を要求するわけではない
- 計算量理論的動機:Arthur-Merlinゲーム，IP = PSPACE定理を結果として提示
- 暗号学的動機:Goldwasser-Micali-Rackoff(1985)の問題設定，パスワード認証やグラフ同型性を具体例に
- 二つの動機が対話型証明系という同じ枠組みに合流することを強調
- 完全性 / 健全性 の形式化，Proof vs Argument の区別

### 第2回:ゼロ知識性とウィットネスの一般化 {#session-2}

[第2回の講義本文を読む →](./session-02)

- シミュレータパラダイムによるゼロ知識性の形式的定義，識別不可能性の階層
- 知識の健全性と抽出器の概念
- 単純なウィットネス(離散対数などの代数的関係)と一般のNP関係(任意の計算)の質的な差
- Schnorr型プロトコルが群の準同型性という構造に直接乗ることで成立している点の確認 → 一般計算にはSchnorrの構造がそのまま与えられているとは限らない → 算術化(arithmetization)の必然性
- 表現力(ウィットネスの一般性)× 効率性(対話性・簡潔性)の2軸マトリクス，計算を委託する用途で簡潔性が求められる理由

| 対象となる関係 | 対話型の例 | 非対話型の例 | 簡潔性を読む際の注意 |
| --- | --- | --- | --- |
| 代数的関係 | Schnorr，Chaum-Pedersen | 条件を満たすΣプロトコルへのFiat-Shamir変換 | 関係に対して短い証明を作れるが，Fiat-Shamir自体が証明を圧縮するわけではない |
| 一般のNP関係 | 一般NP向けの対話型ZK構成 | Groth16 / PLONK / STARK | 非対話性とは別に，計算規模に対する証明サイズ・検証コストを評価する |

## 幕II:道具立て(目的を実現するための言語)— 第3〜10回 {#act-2}

各回で数学的道具とあわせて，暗号学的視点(安全性定義・困難性仮定との対応)と計算量的視点(複雑性クラス・証明能力との関係)を明示する．

### 第3回:有限体・多項式の代数と確率的検査 {#session-3}

[第3回の講義本文を読む →](./session-03)

- 有限体・拡大体と多項式環 $K[X]$ を区別し，既約多項式による拡大体の構成，多項式の除法・剰余・根・Lagrange補間を学ぶ
- 多項式を係数ベクトルや評価表として扱い，偶奇分解からFRIの折り畳み式につなぐ
- **確率・計算量の視点**:Schwartz–Zippel補題で標本集合の大きさと誤り上界を具体例で計算する．PITの片側誤りと，PCP/IOPの健全性検査への接続を確認する

### 第4回:算術化の技法と計算量理論 {#session-4}

[第4回の講義本文を読む →](./session-04)

- Cook–Levin定理と回路計算量(NC，P，一様性)を背景に，公開入力・ウィットネス・中間値を含む計算を制約へ翻訳する
- R1CSを有限体上の線形写像と二次制約として導出し，行列寸法・疎性・ブール値や範囲条件を扱う
- R1CSからQAPへの補間と消失多項式による割り切れ性，AIRの実行トレース・遷移制約・境界制約を比較する
- 入出金総額の一致を題材に，整数の範囲制約と有限体の剰余による回り込みに注意しながら，R1CS/QAPとAIRの表現を追う

### 第5回:誤り訂正符号と情報理論的視点 {#session-5}

[第5回の講義本文を読む →](./session-05)

- Reed–Solomon符号を多項式評価写像として定義し，符号率・最小距離・Singleton限界・誤り訂正と消失復元を導く
- **情報理論的視点**:q元対称通信路の容量をエントロピーから計算し，Hamming球充填限界と最悪ケース誤りを比較する
- 小さな有限体上のBerlekamp–Welch復号例で線形方程式と多項式商を確かめ，一意復号とリスト復号の保証を区別する

### 第6回:Low-Degree Testingと健全性増幅 {#session-6}

[第6回の講義本文を読む →](./session-06)

- Low-Degree TestingをRS符号への近接性検査として定式化し，補間・Merkleコミットメントだけでは低次数性を示せない理由を具体例で確認する
- FRIの偶奇分解・有限体上の折り畳み・段階間の一貫性・最終次数検査を数値例で追う．問い合わせ数，証明通信量，認証経路を区別する
- **暗号学的視点**:健全性増幅の条件，和事象上界，rewindingとforking lemmaの役割を学び，独立性を確認せず誤り確率を掛けない

### 第7回:楕円曲線とペアリング {#session-7}

[第7回の講義本文を読む →](./session-07)

- 有限体上の楕円曲線群と双線形ペアリング $e:G_1\times G_2\to G_T$ を学び，指数の積を検査する性質がGroth16にどうつながるかを確認する
- **暗号学的視点**:離散対数，q-SDH，KEAの問題設定とモデルを区別し，還元証明で何が示され，何が仮定に残るかを読む
- 曲線・群要素・スカラーの型を区別し，BN254やBLS12-381を実装上の例として位置づける

### 第8回:多項式コミットメントと暗号学的コミットメントの理論 {#session-8}

[第8回の講義本文を読む →](./session-08)

- 拘束性と隠蔽性を別々に定義し，多項式の点評価を開示する機能を学ぶ
- KZGのSRS・商多項式・ペアリング検証式を小さな有限体の具体例で追い，基本形は隠蔽性やゼロ知識性を自動では持たないことを確認する
- FRIベースの構成でMerkle木の表への拘束性，FRIの低次数近接性，評価開示の役割を分け，両方式の仮定と通信量を比較する

### 第9回:Fiat-Shamir変換とROMの功罪 {#session-9}

[第9回の講義本文を読む →](./session-09)

- Fiat–Shamir変換でチャレンジをトランスクリプトのハッシュから導く手順と，ハッシュ入力・チャレンジ導出・メッセージ順序を学ぶ
- **暗号学的視点**:ROMでの証明，問い合わせ回数による探索，CGH反例を扱い，対話型IPの健全性がそのまま非対話型へ移るとは限らない理由を考える
- 公開コイン型と秘密コイン型IPを区別し，IP=PSPACEから任意の短い非対話証明が得られるわけではないことを確認する

### 第10回:PCP定理とIOPの枠組み — 計算量理論的総括 {#session-10}

[第10回の講義本文を読む →](./session-10)

- PCP定理の主張を，乱数ビット・問い合わせ数・完全性・健全性誤差の記法とともに読む．文献ごとの記法差も確認する
- PCP，IP，IOPの証明アクセスの違いを比較し，FRIをIOPP，多項式コミットメントをオラクルアクセスの実装として位置づける
- **計算量的視点**:PCPの局所検査から近似困難性へのギャップ帰着を概観し，算術化・IOP・コミットメント・Fiat–Shamirの役割と適用範囲を整理する

## 幕III:統合 — 成り立ちと発展の方向 — 第11〜15回 {#act-3}

### 第11回:Groth16 {#session-11}

[第11回の講義本文を読む →](./session-11)

- QAPの割り切れ性からGroth16の証明生成・検証式までを追い，ペアリングが乗算関係の検証に果たす役割を理解する
- 回路固有のトラステッドセットアップ，証明時の乱数，公開入力処理を区別する．証明は3群要素だが公開入力処理のコストは残る
- 完全性・完全ゼロ知識性と，原論文の汎用双線形群モデルで解析される知識の健全性の根拠を分け，q-SDHだけに還元して説明しない

### 第12回:PLONK {#session-12}

[第12回の講義本文を読む →](./session-12)

- Groth16の回路固有鍵との違いから，universal・updatable SRSと回路固有の前処理を区別する
- PLONKish算術化のセレクタ多項式，ゲート制約，コピー制約を導入し，permutation/grand-product検査の仕組みとランダムチャレンジを読む
- カスタムゲートの表現力・制約次数・列数・開示数を含め，効率のトレードオフを評価する．原論文のKZG型と派生構成を混同しない

### 第13回:STARK {#session-13}

[第13回の講義本文を読む →](./session-13)

- AIRの遷移・境界制約，合成多項式，FRIの低次数近接性，Merkle認証，Fiat–Shamirを一連の構成として読む
- **安全性とコスト**:近接性・表の整合性・公開入力への結び付け・必要なマスキングを区別し，証明サイズと検証作業の見積もりモデルを読む
- 透明性・トラステッドセットアップ・量子安全性の仮定を区別し，ハッシュベースであることだけでゼロ知識性やポスト量子安全性が自動的に得られるわけではないと確認する

### 第14回:統合的視点 — 幕I〜IIIの往還 {#session-14}

[第14回の講義本文を読む →](./session-14)

- 完全性・健全性・知識の健全性・ゼロ知識性を別の保証として整理し，三方式それぞれで必要な構成と前提を照合する
- 算術化・コミットメント・非対話性・セットアップ・公開入力コストを比較し，証明サイズや検証時間の主張に含まれる条件を確認する
- 暗号学的仮定と理論モデルを対応づけ，単純な安全性ランキングを避けて設計判断を説明する

### 第15回:発展の方向性 {#session-15}

[第15回の講義本文を読む →](./session-15)
- 再帰的証明による証明の合成，楕円曲線サイクルの役割，Novaの緩和R1CS folding・IVC・圧縮を区別する
- SumcheckとGKRの層ごとの言明縮約を学び，検証者・証明者コストの利点を方式ごとの条件とともに評価する
- **応用と研究動向**:EthereumのL2 zk rollupとL1実行証明を区別し，EIP-8025の任意実行証明の位置づけを確認する．記載するステータスには確認日を付す
- 表現力・証明サイズ・検証コスト・証明者コスト・セットアップ・安全性の軸で研究課題を整理する
