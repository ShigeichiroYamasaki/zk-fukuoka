# 補間・消失多項式・割り切れ性

[第4回へ戻る](../session-04) · [用語ガイド](./) · [前提知識と補助教材](../foundations)

多項式環そのものから確認したい場合は，[第3回の多項式環の基礎](../session-03#_3-1-定義と基本操作)から読み，[根・消失多項式・QAPの割り切れ性](../session-03#qap-polynomial-prerequisites)へ進んでください．

## 表を多項式で読む

QAPでは，制約の行番号を相異なる体の元に対応させる．列に並んだ数を，その点での多項式の値として表すのが補間である．$m$ 個の相異なる点と値を指定すると，次数 $m$ 未満の補間多項式が一意に決まる．

小さな例として，$\mathbb F_{101}$ で点1に値3，点2に値5を対応させる．補間多項式は $P(X)=2X+1$ で，$P(1)=3,P(2)=5$ である．補間は値を推測する処理ではなく，指定された値を正確に通る多項式を作る処理である．

## 消失多項式と割り切れ性

点の集合 $D=\{1,2\}$ に対し，消失多項式は

$$Z_D(X)=(X-1)(X-2)=X^2-3X+2$$

である．二つの点でともに0になる．ある多項式 $F$ がその両方で0なら，因数定理により $Z_D$ で割り切れる．

たとえば $F(X)=3X^2-9X+6$ は $F=3Z_D$ なので商は3である．一方，$G(X)=F(X)+1$ は点1でも点2でも1となり，割り切れない．計算はすべて体上で行い，負の係数も法101で読める．

## QAPへの接続

R1CSの列を補間した多項式を $A_i,B_i,C_i$ とする．割当 $z$ を重みとして合成し，

$$F(X)=\left(\sum_i z_iA_i(X)\right)\left(\sum_i z_iB_i(X)\right)-\sum_i z_iC_i(X)$$

を作る．各制約点で $F$ が0になることは，各行の制約が成立することに等しい．そこで $F=HZ_D$ とまとめる．**多項式の変数 $X$ は制約の行を符号化するための変数であり，元の秘密入力 $x$ とは役割が違う．**

## 一点で検査するときの条件

ランダムな $r$ で $F(r)=H(r)Z_D(r)$ を確かめるだけで絶対的な一致は分からない．固定された非零の差の多項式について，次数に応じた確率的保証を使う．チャレンジを見てから多項式を自由に変えられるなら，この議論は使えない．次数の制限と，多項式を事前に固定する仕組みは証明系側の仕事である．

## 確認問題

点1，2で同じ値を持つ二つの多項式は，必ず同じ多項式だろうか．

::: details 解答
次数が2未満という条件があれば同じである．次数制限がなければ $P(X)$ と $P(X)+Z_D(X)$ は二つの点で一致するが，異なる多項式である．
:::
