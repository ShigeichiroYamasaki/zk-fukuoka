# 集合・所属記号・言語：x ∈ L を読む

[第1回へ戻る](../session-01) · [前提知識と補助教材](../foundations) · [トピック別](../topics)

更新日：2026年9月28日

## 1. 集合と要素：∈は「に属する」

集合は，対象をまとめたものであり，その中の一つ一つを要素という．例えば $A=\{2,4,6\}$ なら，$4\in A$ は「4はAの要素である」，$3\notin A$ は「3はAの要素ではない」と読む．$\in$ は等号ではない．4という一つの数と，Aという集合を同じものだと言っているのではない．

| 記号 | 読み方 | 例 |
| --- | --- | --- |
| $x\in A$ | xはAの要素である | $4\in\{2,4,6\}$ |
| $x\notin A$ | xはAの要素ではない | $3\notin\{2,4,6\}$ |
| $A\subseteq B$ | Aのすべての要素はBにも属する | $\{2,4\}\subseteq\{2,4,6\}$ |
| $\{x\mid C(x)\}$ | 条件Cを満たすx全体の集合 | $\{n\in\mathbb{Z}\mid n>0\}$ は正の整数全体 |

## 2. 計算問題を文字列で表す

コンピュータに入力する数・グラフ・プログラムは，いずれも有限の文字列として符号化できる．使える文字の集合をアルファベット $\Sigma$ と呼ぶ．例えば $\Sigma=\{0,1\}$ なら，`0`，`101`，`1100` などが文字列である．$\Sigma^*$ は空文字列も含めた有限長の文字列全体の集合を表す．星印は，ここでは掛け算ではない．

入力を表す文字列を $x$ と書く．$|x|$ はその長さであり，入力の数値そのものではない．例えば二進表現 `1100` は数12を表すが，文字列の長さは4である．グラフを扱う場合，$x$ は頂点と辺を符号化したデータになる．

## 3. 言語Lは「答えがYesになる入力の集合」

計算量理論でいう**言語**は，日本語や英語のことではなく，文字列の集合 $L\subseteq\Sigma^*$ である．Yes/Noで答える判定問題では，**答えがYesになる入力を集めた集合**をLとして，問題を表せる．したがって，

$$x\in L$$

は「入力xは，この問題のYesの集合に属する」，つまり「入力xについての主張が正しい」という意味になる．$x\notin L$ はNoの場合である．

例えば，Lを「二進表現された非負整数のうち，偶数を表す文字列全体」とする．`1100` は12なのでLに属し，`1101` は13なのでLに属さない．集合Lはあらかじめ問題によって定まる．**検証者が受理したから，その入力がLの要素になるわけではない．**

より講義に近い例として，Lを「充足可能なブール論理式を符号化した文字列全体」としてみよう．$x$ が式 $a\land b$ を表すなら，$a=b=1$ という割当があるので $x\in L$ である．$x$ が $a\land\neg a$ を表すなら，どの割当でも真にならず $x\notin L$ である．符号化の形式に合わない文字列は，この言語には含めないと決めておく．

## 4. x ∈ L と L ∈ NP は，集合の階層が違う

$x$ は一つの入力，$L$ は入力の集合，$\mathrm{NP}$ は一定の条件を満たす言語の集まりである．

- $x\in L$：この入力の答えはYesである．
- $L\in\mathrm{NP}$：この判定問題のYesの入力には，短いウィットネスを使って効率よく検査できる仕組みがある．

NPに属することは，すべての入力の答えがYesであることでも，必ず解くのが難しいことでもない．上の偶数の例もNPに属するが，ウィットネスを使わず簡単に判定できる．

## 5. 第1回の式を読む

$$x\in L\iff\exists w,\ |w|\le\mathrm{poly}(|x|),\ V(x,w)=1$$

$\iff$ は「必要十分」，$\exists$ は「存在する」と読む．$w$ はウィットネス，$V$ は検証アルゴリズム，1は受理を表す．$\mathrm{poly}(|x|)$ は，入力長に関するある固定された多項式による上限の略記である．NPの定義では，Vも入力長に対して多項式時間で検査できることを要求する．

この式は「入力xの答えがYesであることと，長さの上限内にありVが受理するウィットネスwが少なくとも一つ存在することは同値である」と読む．論理式の例では，xが式のデータ，wが変数の割当になる．**xとwは役割が違う．**さらに詳しくは[NP関係・公開入力・ウィットネス](./np-relations)と[多項式時間・計算量](./complexity)へ進もう．

第1回の完全性は $x\in L$ の場合，健全性は $x\notin L$ の場合を扱う．こちらの対話型証明では受理は確率的な出来事なので，受理という結果と，集合への所属という事実を区別することが重要になる．

## 6. 確認問題

1. $A=\{1,3,5\}$ のとき，$3\in A$ と $\{3\}\subseteq A$ はそれぞれ何を比較しているか．
2. $x\in L$ と「検証者がxを受理した」は常に同じ意味か．
3. 充足可能性の例で，論理式とその変数への割当のどちらがxで，どちらがwか．

<details>
<summary>解答</summary>

1. 前者は要素と集合，後者は集合と集合の関係である．どちらも正しい．
2. 同じではない．所属は問題の定義で決まり，検証者には誤受理の可能性がある．
3. 論理式を符号化した入力がx，その式を真にする割当がwである．

</details>
