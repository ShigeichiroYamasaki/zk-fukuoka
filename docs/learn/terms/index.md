## おすすめの読む順序

公開する主張とウィットネス → 回路 → 制約 → 翻訳の一般性 → 計算のコスト → 行列による表現 → 多項式 → 実行トレース，の順に進みます。

共通の計算例は $\mathbb F_{101}$ 上の $x^3+x+5=35$ です。整数について主張する場合は範囲の条件が必要になることも確認します。実行トレースのページでは，二乗を繰り返す別の例を使います。
