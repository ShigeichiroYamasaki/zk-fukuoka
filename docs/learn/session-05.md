# 第5回:誤り訂正符号と情報理論的視点

## 本講義の位置づけと到達目標

前回、算術化によって計算を多項式(あるいはその評価点表現)へと翻訳する技法を学んだ。今日からは視点を変え、**「多項式として符号化された情報を、どのくらい信頼して扱えるか」**という問いに取り組む。これは符号理論・情報理論の言葉で捉え直すことができる。

到達目標は次の3点:

1. Reed-Solomon符号を、多項式の評価点表現の自然な符号化として理解する
2. 情報理論的な視点(Shannon限界とHamming限界)から、誤り訂正符号の性能をどう評価するかを把握する
3. list decodingという発展的な概念に触れ、それが後の健全性の定量的評価にどうつながるかを予告的に理解する

今日の内容は、次回(第6回)のLow-Degree Testing・FRIの土台であると同時に、証明の「頑健性」を情報理論の言葉で測るという、幕II全体の中でもやや異質だが重要な視点を提供する回である。

---

## 1. なぜ符号理論が必要になるのか — 動機

### 1.1 算術化だけでは足りない理由

前回、計算を多項式の制約として表現する方法(R1CS/QAP/AIR)を学んだ。しかし、検証者が実際に多項式を「確認」する際、証明者から送られてきた情報がどこまで信頼できるかという問題が残る。特に、証明者が不正直で、本来低次数であるべき多項式の代わりに、細工した(低次数でない)関数を送ってきた場合、それをどう検出すればよいか。

この問いに答える準備として、まず**符号(code)**という概念、特にReed-Solomon符号を導入する。

### 1.2 符号理論の基本的な問い

符号理論は元来、通信路にノイズが入ることを前提に、「元のメッセージをどこまで正確に復元できるか」を扱う分野である。この発想を証明系に応用すると、「証明者が送ってきた(ノイズを含むかもしれない)データから、意図された正しい多項式をどこまで頑健に検出・復元できるか」という問いに読み替えられる。

---

## 2. Reed-Solomon符号

### 2.1 定義

次数 $d$ 未満の多項式全体 $\{f \in \mathbb{F}[X] : \deg f < d\}$ を、評価点集合 $D = \{x_1, \dots, x_n\} \subseteq \mathbb{F}$($n > d$)における値のベクトルへ写す符号化:

$$f \mapsto (f(x_1), f(x_2), \dots, f(x_n))$$

これがReed-Solomon符号(RS符号)である。符号語(codeword)は、次数 $d$ 未満の多項式の評価点表現そのものであり、前回学んだLagrange補間(第3回)による係数表現↔評価点表現の対応が、ここでそのまま符号化・復号の理論的基盤になっている。

### 2.2 最小距離

符号の性能を測る基本的な指標が**最小距離**である。RS符号の最小距離は

$$\delta = n - d + 1$$

で与えられる(これは第3回で確認した「次数 $d-1$ 以下で恒等的に0でない多項式の根は高々 $d-1$ 個」という事実、すなわち異なる2つの符号語は高々 $d-1$ 個の点でしか一致できないことから従う)。この最小距離が大きいほど、より多くの誤りを訂正できる。

### 2.3 誤り訂正能力

最小距離 $\delta$ の符号は、$\lfloor (\delta - 1)/2 \rfloor$ 個までの誤りを一意に訂正できる、というのが符号理論の基本原理である。RS符号は与えられたパラメータ($n$, $d$)に対して最小距離が理論限界(Singleton限界)に一致する、**MDS符号(Maximum Distance Separable)**であることも触れておく。

---

## 3. 情報理論的な視点:Shannon限界とHamming限界

### 3.1 二つの異なる誤りモデル

符号理論には、誤りをどうモデル化するかによって大きく2つの流儀がある。

**Shannon的モデル(確率的誤り)**:各シンボルが独立にある確率でランダムに誤る、という確率的な通信路を仮定する。Shannon限界は、この確率的誤りのもとで「情報を確実に伝送できる最大レート」を与える。

**Hamming的モデル(最悪ケース誤り)**:誤りの位置・内容について確率的な仮定を置かず、最悪の場合にどこまで誤りが入りうるかを考える。Hamming限界(球充填限界)は、この最悪ケースの誤りに対して符号が達成できる限界を与える。

### 3.2 なぜこの区別が証明系にとって重要か

証明系の文脈では、誤り(=証明者の不正)は確率的な自然現象ではなく、**悪意を持って最悪のケースを狙ってくる敵対者**によって引き起こされる。したがって、証明系の健全性を論じる際には、Shannon的な確率的誤りモデルではなく、**Hamming的な最悪ケースモデル**に基づいた符号の性質(最小距離、誤り訂正能力)が本質的に重要になる。この対比を意識しておくことは、暗号学的な安全性の考え方(平均的にではなく最悪の敵対者に対して安全性を保証する)とも一貫している。

---

## 4. List Decoding という発展的な考え方

### 4.1 一意復号の限界

最小距離に基づく一意復号は、誤りの個数が $(\delta-1)/2$ を超えると保証を失う。しかし、誤りの個数がそれより大きくても、「候補となる符号語のリスト」を出力することならできる場合がある。これが**list decoding**の発想である。

### 4.2 なぜこの概念が重要か(予告)

RS符号は、Johnson限界と呼ばれる範囲まで効率的なlist decodingが可能であることが知られている(Guruswami-Sudanのアルゴリズムなど)。この事実は、次回扱うLow-Degree Testing・FRIにおいて、「検証者がある程度誤りを許容しつつ、それでもなお健全性を定量的に保証できる」ための土台になる。具体的には、FRIの健全性誤差をどこまで小さくできるかという評価が、list decodingでどこまで効率的に復号できるかという符号理論的なパラメータと直結している。

*(list decodingの具体的なアルゴリズムには立ち入らない。今日は「一意復号を超えて、どこまで頑健に情報を取り出せるか」という考え方があることと、それが次回以降の健全性評価の土台になることを押さえるにとどめる。)*

## 5. 演習:最小距離とパラメータ設計

講義内で次のような具体例を扱う:

- 具体的な $n, d$ を与え、最小距離と誤り訂正能力を計算させる
- 有限体の範囲内で評価点集合 $D$ を小さく取る場合と大きく取る場合とで、符号のレート($d/n$)と誤り訂正能力のトレードオフがどう変わるかを議論する
- 「なぜ $n$ を大きくしすぎると効率(証明者の計算コスト)が悪化するのか」という、次回以降のFRIの設計判断への伏線となる問いを投げかける

## まとめと次回予告

今日学んだこと:

- Reed-Solomon符号:次数制限のある多項式の評価点表現としての符号化。第3回のLagrange補間の対応関係がそのまま符号理論の基盤になっていること
- 最小距離と誤り訂正能力の関係、RS符号がSingleton限界を達成するMDS符号であること
- Shannon的(確率的)モデルとHamming的(最悪ケース)モデルの違い、証明系の健全性評価にはHamming的モデルが本質的であること
- List decodingという発展的な考え方が、次回のFRIの健全性評価の土台になること

次回(第6回)は、いよいよLow-Degree Testingの具体的な技法であるFRIを扱う。今日学んだ符号理論的な道具を使って、「証明者が送ってきた関数が本当に低次数の多項式に近いか」を効率的に検査する仕組みを見ていく。あわせて、健全性増幅の一般論、rewindingやforking lemmaといった暗号学的な証明技法も導入する。
