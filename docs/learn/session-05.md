## 本講義の位置づけと到達目標

前回は，計算を多項式の制約に翻訳した．今日は，その多項式の値が並んだ表を受け取ったとき，何を確認すべきかを考える．表の一部が違っていても元の情報を特定できるだろうか．そもそも，低次数多項式から作られた表と，そうでない表は，どれくらい違うのだろうか．この問いを扱う道具が符号理論である．

到達目標は次の3点:

1. Reed-Solomon符号を，多項式の評価点表現の自然な符号化として理解する
2. 情報理論的な視点(Shannon限界とHamming限界)から，誤り訂正符号の性能をどう評価するかを把握する
3. リスト復号という発展的な概念に触れ，それが後の健全性の定量的評価にどうつながるかを予告的に理解する

今日の内容は，次回(第6回)のLow-Degree Testing・FRIの土台であると同時に，証明の「頑健性」を情報理論の言葉で測るという，幕II全体の中でもやや異質だが重要な視点を提供する回である．

---

## 1. なぜ符号理論が必要になるのか — 動機

### 1.1 算術化だけでは足りない理由

算術化は，正しい計算が満たすべき条件を与える．しかし，証明者が提出した表が，その条件を適用してよい種類の表とは限らない．低次数であるはずの多項式の代わりに，都合のよい値を各点で別々に選んでいるかもしれない．まず，正しい形の表とは何か，そこからのずれをどう測るかを定めよう．

この問いに答える準備として，まず**符号(code)**という概念，特にReed-Solomon符号を導入する．

### 1.2 符号理論の基本的な問い

通信では，途中でデータが変わっても，元のメッセージを復元したい．そのために，あらかじめ冗長な情報を加える．証明系でも，許された形のデータ同士が十分離れていれば，不正なデータを検出する手掛かりになる．ただし，通信のノイズと証明者の不正は同じ原因ではない．後で誤りのモデルを分けて考える．

---

## 2. Reed-Solomon符号

### 2.1 定義

次数 $d$ 未満の多項式全体 $\{f \in \mathbb{F}[X] : \deg f < d\}$ を，評価点集合 $D = \{x_1, \dots, x_n\} \subseteq \mathbb{F}$($n > d$)における値のベクトルへ写す符号化:

$$f \mapsto (f(x_1), f(x_2), \dots, f(x_n))$$

この写像がReed-Solomon符号である．多項式を決めた後で，多項式を特定するのに必要な数より多くの点を評価している．余分な評価値は無関係な情報ではなく，同じ多項式から計算された値である．この関係が冗長性になる．第3回の補間を，今度は情報を保護するための表現として読み直そう．

### 2.2 最小距離

異なる二つのメッセージが，ほとんど同じ表になると，少しの誤りで区別できなくなる．そこで，異なる符号語が少なくとも何か所違うかを測る．これが**最小距離**である．次数上限を前節のように定めたRS符号では，次の値になる．

$$\delta = n - d + 1$$

で与えられる(これは第3回で確認した「次数 $d-1$ 以下で恒等的に0でない多項式の根は高々 $d-1$ 個」という事実，すなわち異なる2つの符号語は高々 $d-1$ 個の点でしか一致できないことから従う)．この最小距離が大きいほど，より多くの誤りを訂正できる．

### 2.3 誤り訂正能力

最小距離が $\delta$ なら，各符号語の周りで $\lfloor(\delta-1)/2\rfloor$ 個まで値を変えても，他の符号語の同じ範囲とは重ならない．これが一意に訂正できる理由である．RS符号は，長さ $n$ と次元 $d$ に対するSingleton限界を達成するMDS符号である．距離の大きさが，許容できる誤りの数にどう対応するかを確認しておこう．

## 3. 情報理論的な視点:Shannon限界とHamming限界

### 3.1 二つの異なる誤りモデル

誤りを何個訂正できるかを問う前に，誤りがどう発生すると考えているかを決める必要がある．自然な雑音として確率で扱う場合と，相手が意図的に位置や値を選ぶ場合では，求める保証が違う．

**Shannon的モデル(確率的誤り)**では，通信路を確率法則で表す．各シンボルが独立に誤る通信路はその一例である．通信路容量は，復号誤り確率を漸近的に小さくしながら伝送できるレートの限界を与える．「確実」という言葉を，有限長で誤りが必ず0になる意味に読まないようにしよう．

**Hamming的モデル(最悪ケース誤り)**:誤りの位置・内容について確率的な仮定を置かず，最悪の場合にどこまで誤りが入りうるかを考える．Hamming限界(球充填限界)は，この最悪ケースの誤りに対して符号が達成できる限界を与える．

### 3.2 なぜこの区別が証明系にとって重要か

検証者は，証明者の間違い方が独立なランダムノイズだとは仮定できない．証明者は，検査を通りやすい場所や値を選ぶかもしれない．そのため，表が符号語からどれだけ離れているかという，最悪ケースでも使える性質が必要になる．検証者がランダムに問い合わせることと，誤り自体をランダムだと仮定することは別である．

## 4. リスト復号 という発展的な考え方 {#_4-list-decoding-という発展的な考え方}

### 4.1 一意復号の限界

誤りの個数が $(\delta-1)/2$ を超えると，元の符号語を一つに決められない場合がある．それなら，「必ず一つに決める」という要求を緩めたらどうだろうか．指定した距離の範囲にある候補を，短いリストとして取り出すことを考える．これがリスト復号である．

### 4.2 なぜこの概念が重要か(予告)

RS符号では，Guruswami–Sudanのアルゴリズムなどにより，Johnson限界に関係する範囲でリスト復号を行える．FRIの解析でも，近くにどれだけの低次数多項式がありうるかが重要になる．ただし，検証者が毎回リスト復号を実行するという意味ではない．候補の数や距離に関する符号の性質を，健全性誤差の評価に使うのである．

*(リスト復号の具体的なアルゴリズムには立ち入らない．今日は「一意復号を超えて，どこまで頑健に情報を取り出せるか」という考え方があることと，それが次回以降の健全性評価の土台になることを押さえるにとどめる．)*

## 5. 演習:最小距離とパラメータ設計

式を使って，評価点を増やすと何が変わるかを調べよう．訂正できる誤りだけでなく，送るデータや計算する評価値も増える．次の例では，得られる保証と必要な作業を対にして考える．

- 具体的な $n, d$ を与え，最小距離と誤り訂正能力を計算させる
- 有限体の範囲内で評価点集合 $D$ を小さく取る場合と大きく取る場合とで，符号のレート($d/n$)と誤り訂正能力のトレードオフがどう変わるかを議論する
- 「なぜ $n$ を大きくしすぎると効率(証明者の計算コスト)が悪化するのか」という，次回以降のFRIの設計判断への伏線となる問いを投げかける

---

## まとめと次回予告

今日は，多項式の評価値の表を，符号として読み直した．表同士の距離が，誤りを見分ける力にどうつながったかを確認しよう．

- Reed-Solomon符号:次数制限のある多項式の評価点表現としての符号化．第3回のLagrange補間の対応関係がそのまま符号理論の基盤になっていること
- 最小距離と誤り訂正能力の関係，RS符号がSingleton限界を達成するMDS符号であること
- Shannon的(確率的)モデルとHamming的(最悪ケース)モデルの違い，証明系の健全性評価にはHamming的モデルが本質的であること
- リスト復号という発展的な考え方が，次回のFRIの健全性評価の土台になること

次回(第6回)は，いよいよLow-Degree Testingの具体的な技法であるFRIを扱う．今日学んだ符号理論的な道具を使って，「証明者が送ってきた関数が本当に低次数の多項式に近いか」を効率的に検査する仕組みを見ていく．あわせて，健全性増幅の一般論，rewindingやforking lemmaといった暗号学的な証明技法も導入する．
