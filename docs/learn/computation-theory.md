# 言語と計算理論

このページでは，ZK Fukuokaの授業を読むための言語理論・計算理論の前提を，基本用語・例・自己確認の順に整理する．扱う概念は，形式言語，オートマトン，チューリング機械，計算量，帰着である．

## このページで押さえる範囲

教科書の全範囲を読む必要はない．この講義では，次の流れを理解すれば十分である．

1. 記号列の集合として問題を表し，入力がその集合に属するかを問う．
2. 受理する計算手続きと，その計算に必要な時間を考える．
3. 「答えを知っている」ことを，短いウィットネスと効率的な検証手続きで表す．
4. NPの問題を回路充足可能性へ変換し，その回路を算術化して証明系に渡す．

有限オートマトン，文脈自由文法，プッシュダウン・オートマトンは，言語を認識する計算モデルの違いを知るために短く扱う．zk-SNARK/STARKの前提として，正規言語や文脈自由言語の詳細な性質を証明する必要はない．

## 1．アルファベット・記号列・言語

**アルファベット** $\Sigma$ は，入力に使う記号の有限集合である．たとえば $\Sigma=\{0,1\}$ とする．この記号を有限個並べたものが**記号列**で，空列を $\varepsilon$ と書く．$\Sigma^*$ は，長さ0以上のすべての記号列の集合を表す．

**言語** $L$ は，$\Sigma^*$ の部分集合である．したがって「入力 $x$ が言語 $L$ に属するか」は，計算問題を集合への所属として書いたものになる．記号 $x\in L$ は「$x$ が $L$ に属する」という意味である．たとえば，$L_{\mathrm{even}}$ を「1の個数が偶数であるビット列の集合」とすると，$1011\in L_{\mathrm{even}}$ である（1が3個なので，これは誤り）．正しくは $1010\in L_{\mathrm{even}}$ である．

この例では入力そのものを数えて所属を決める．一方，NPでは，入力に加えて「所属を確かめる助けになるウィットネス」がある場合を扱う．

## 2．言語とウィットネス：NP関係 {#np-relations}

**関係** $R(x,w)$ は，入力 $x$ と候補 $w$ の組が条件を満たすかを表す述語である．関係が多項式時間で判定でき，受理される $w$ の長さにも多項式上限があるとき，次の言語を考えられる．

$$L_R=\{x\mid \exists w,\ R(x,w)=1\}$$

つまり，$x\in L_R$ であることと，「条件を満たすウィットネス $w$ が少なくとも一つ存在する」ことは同じである．検証者は $w$ を受け取って $R(x,w)$ を計算する．ウィットネスは検証者に提出される情報のモデルであり，ゼロ知識証明では，それ自体を明かさずに関係を満たすことを証明する方法を学ぶ．

### 例：充足可能な回路

ブール回路 $C$ の入力を $x$，回路を満たす割当てを $w$ とする．関係を $R(C,w)=1$（$C$ に $w$ を入力した出力が1）と定義すれば，言語は

$$\mathrm{CircuitSAT}=\{\langle C\rangle\mid \exists w,\ C(w)=1\}$$

となる．言明は「回路 $C$ は充足可能である」，ウィットネスは「出力を1にする入力割当て $w$」である．検証者は $w$ 全体を受け取って回路を評価すればよい．第1回・第2回では，この素朴な検査を対話型・ゼロ知識の検査へどう変えるかを考える．

## 3．認識器：有限オートマトンからチューリング機械へ

**認識器**は，記号列を読み，その入力を受理するかどうかを決める計算モデルである．計算モデルを変えると，認識できる言語の範囲と必要な計算資源が変わる．

### 有限オートマトン

決定性有限オートマトン（DFA）は，有限個の状態，入力アルファベット，状態遷移，初期状態，受理状態で定まる．状態は，これまで読んだ入力から今後の判定に必要な情報だけを保持する有限メモリと見なせる．

例として，0と1の列に含まれる1の個数が偶数かを判定する機械は，「偶数個を読んだ状態」と「奇数個を読んだ状態」の2状態で足りる．0を読むと状態は変わらず，1を読むと2状態の間を移動する．このようにDFAが受理する言語を**正則言語**という．

このモデルは，有限の状態だけで処理できる入力形式や，単純な構文条件を考える助けになる．ただし任意のプログラムや算術回路を有限オートマトンそのものとして表すわけではない．

### 文法とスタック：必要な位置づけ {#grammars-stacks}

文脈自由文法（CFG）は，生成規則で記号列を記述する形式であり，括弧の対応のような入れ子構造を表現できる．プッシュダウン・オートマトン（PDA）はスタックを備え，CFGと対応する言語を認識する．この段階は「有限状態より強い記憶が必要になる」ことを理解するための比較である．本講義では，CFGの正規形やPDAとの等価性の証明は必須範囲にしない．

### チューリング機械

チューリング機械は，有限な制御状態に加え，読み書きできるテープを持つ抽象的計算モデルである．アルゴリズムが入力を読み，作業用の情報を更新し，停止する過程を形式的に考えるために使う．計算の各時点の状態・テープ内容・読み取り位置をまとめたものを**構成**と呼ぶ．計算は，初期構成から次の構成へ移る列として表せる．

## 4．決定可能性と計算量

チューリング機械がすべての入力で停止し，受理する入力と拒否する入力を正しく分けるなら，その言語は**決定可能**である．受理する入力では停止するが，属さない入力では停止しないことも許す機械を認識器と呼ぶ．この違いは「答えが出る」保証があるかに関わる．

### 入力長と時間計算量

入力の大きさは数値の値そのものではなく，通常はその符号化に必要な記号数 $n=|x|$ で測る．時間計算量 $T(n)$ は，長さ $n$ の入力に対して計算が何ステップ必要かを表す．多項式時間とは，ある定数 $k$ に対して $T(n)\leq c n^k$ となることをいう．多項式時間は計算可能性のすべてを表すのではなく，この講義では「効率的」の代表的な理論基準として用いる．

- **P**：決定性チューリング機械で多項式時間に解ける言語のクラス．
- **NP**：多項式長のウィットネスが存在するとき，決定性多項式時間でその正しさを検証できる言語のクラス．
- **PSPACE**：多項式量の作業領域で解ける言語のクラス．時間には多項式上限を要求しない．

NPの「N」はランダム性を意味しない．非決定性計算を，候補ウィットネスを与えて検証する形式に置き換えて定義できる，という点を押さえる．また，言語がNPに属することは，そのまま短いゼロ知識証明や簡潔な非対話証明があることを意味しない．

## 5．計算量の帰着：回路充足可能性へ

**多項式時間帰着**は，ある問題の入力を別の問題の入力へ効率よく変換し，元の入力が受理される場合と変換後が受理される場合とを一致させる方法である．問題 $A$ が $B$ に帰着できれば，$B$ を解く方法を使って $A$ も解ける．

Cook–Levinの定理は，すべてのNP言語がCircuitSATへ多項式時間で帰着できることを示す．したがってCircuitSATはNP完全であり，NPの問題に共通する計算構造を回路として調べる基盤になる．講義では定理の証明を再現するのではなく，この帰着が「一般の計算を回路として表し，回路の正しい実行を検査する」ことを正当化する点を使う．

## 6．対話型証明から算術化へ

古典的なNP検証では，検証者は候補ウィットネスを読み，関係 $R(x,w)$ を計算する．対話型証明では検証者が証明者に質問でき，健全性・完全性・ゼロ知識性を別々に定義する．第1回のIP=PSPACEは，対話と確率的検証が計算能力に何を加えるかを示す計算量理論上の結果であり，すべての問題に短い非対話証明を与える主張ではない．

算術化では，回路の入力・中間値・出力の関係を有限体上の制約に置き換える．第4回では，R1CS・QAP・AIRをこの目的に使う．チューリング機械の構成列を直接暗号化するのではなく，対象計算を回路または実行トレースに表し，必要な制約がすべて成立することを示す，という段階を区別しよう．

## 7．理解度チェック

1. $\Sigma=\{0,1\}$ のとき，$\Sigma^*$ に含まれるものを一つ挙げ，言語 $L$ との違いを説明する．
2. CircuitSATの入力・言語への所属条件・ウィットネスをそれぞれ答える．
3. 有限オートマトンで「これまでに読んだ1の数が偶数か」を判定するとき，なぜ状態が2つで足りるか説明する．
4. NPが「ランダムに答えを試す計算」ではない理由を，ウィットネス検証で説明する．
5. CircuitSATへの帰着が，R1CS/QAPを学ぶ前段として役立つ理由を説明する．

::: details 解答例
1. `010` は $\Sigma^*$ の要素である．$\Sigma^*$ はすべての有限列，$L$ はその中から条件を満たす列だけを選んだ部分集合である．
2. 入力は回路 $C$ の符号化，所属条件は $C$ を満たす割当てが存在すること，ウィットネスはその割当てである．
3. 次の判定に必要なのは1の個数の正確な値ではなく偶奇だけであり，「偶数」「奇数」の2状態で記録できる．
4. NPの検証者は与えられた候補ウィットネスを決定性手続きで検査する．ランダム性はNPの定義に含まれない．
5. CircuitSATがNP完全なので，一般のNP計算を回路の充足性へ帰着してから，回路の各制約を算術化する道筋が得られる．
:::
