## 本講義の位置づけと到達目標

前回は対話型証明の背景(前提B:非対話性への問い)を扱った。今日は残されたもう一つの問い、**前提A(全開示性)への問い**に正面から取り組む。到達目標は次の3点:

1. ゼロ知識性を シミュレータパラダイム によって形式的に定義し、識別不可能性の階層を理解する
2. 知識の健全性と 抽出者 という「証明者が本当にウィットネスを知っているか」を保証する概念を導入する
3. ウィットネスが単純な代数的対象(離散対数)から一般の計算へと拡張されることの**質的な**意味を理解し、それが幕II全体を貫く2つの軸(表現力・効率性)として整理できることを見る

今日で幕I(目的と動機)が完結する。次回からは幕II、道具立てのパートに入る。

---

## 1. 導入:「秘密を明かさずに証明する」を厳密に定義する

前回GMRの問題設定(秘密を明かさずに、知っていることを証明する)を紹介した。しかし「秘密を明かさない」とは、正確には何を意味するのだろうか。

素朴には「検証者にウィットネス $w$ を送らなければよい」と思うかもしれない。しかし、それだけでは不十分である。対話の**過程**そのものから、ウィットネスに関する部分的な情報が漏れる可能性があるからだ。たとえば、証明者の応答のタイミング、応答の統計的な偏り、あるいは複数の証明を重ねることで得られる情報の蓄積などである。

「何も漏れない」ことをどう定式化すればよいか。ここでGMRが到達したのが **シミュレータパラダイム** という発想である。

---

## 2. シミュレータパラダイム によるゼロ知識性の定義

### 2.1 核心のアイデア

ゼロ知識性の定義の核心は次のように表現できる:

> 検証者が対話から得られるものはすべて、**ウィットネスを知らなくても自分一人でシミュレートできる**ものでしかない

つまり、対話の書き起こし(transcript)を生成できるアルゴリズム(シミュレータ $S$)が、ウィットネス $w$ にアクセスすることなく、本物の対話と「見分けがつかない」分布を出力できるなら、その対話は本質的に何も新しい情報を検証者に与えていない、とみなす。

### 2.2 形式的定義

対話型証明系 $(P, V)$ が言語 $L$(関係 $R$)に対して**ゼロ知識**であるとは、任意の(悪意ある可能性のある)検証者 $V^*$ に対して、あるシミュレータ $S$ が存在し、

$$\{\langle P(w), V^*\rangle(x)\}_{x \in L} \approx \{S(x)\}_{x \in L}$$

が成り立つことをいう。ここで $\approx$ は「識別不可能性」を表す記号であり、その厳密さの水準によって次の3段階に分かれる:

- **完全ゼロ知識(perfect ZK)**:2つの分布が完全に一致する
- **統計的ゼロ知識(statistical ZK)**:2つの分布の統計距離が無視できるほど小さい
- **計算量的ゼロ知識(computational ZK)**:計算量的に制限された識別者では2つの分布を区別できない

実用上のzk-SNARK/zk-STARKの多くは計算量的ゼロ知識を目指す。この階層は、前回のProof/Argumentの区別(証明者の計算能力をどう制限するか)と対をなす、「検証者・識別者の計算能力をどう制限するか」という軸であることに注意してほしい。

### 2.3 直感の確認

シミュレータがウィットネスなしで対話を「捏造」できるという発想は、初見では奇妙に感じられるかもしれない。ここで有効なのは、離散対数の等価性証明(Chaum–Pedersenプロトコルなど)を例に、シミュレータがどうやって「先にレスポンスを選んでからチャレンジを合わせる」という順序の入れ替えによって対話を捏造するかを、簡単にスケッチしてみせることである。厳密な構成は幕IIで代数的道具を整えたあとに扱うが、直感だけここで共有しておくと後の理解が早い。

## 3. 知識の健全性と 抽出者

### 3.1 なぜ 健全性だけでは足りないか

前回定義した健全性は「$x \notin L$ なら受理されない」ことしか保証しない。しかし暗号学的な応用の多くでは、それ以上の保証、すなわち「証明者が実際にウィットネス $w$ を**知っている**」という保証が必要になる。たとえば認証プロトコルでは、単に $x \in L$ であることだけでなく、目の前の証明者が本当に秘密を持っていることを確認したい。

### 3.2 抽出者 の概念

この要求を定式化するのが **知識の健全性** である。直感的には次のように定義される:

> 証明者 $P^*$ が検証者を高い確率で納得させられるなら、$P^*$ と同じ入出力にアクセスできる**抽出者** $E$ が、$P^*$ を(必要ならば巻き戻しながら)観察することで、実際にウィットネス $w$ を効率的に取り出せる

この定義により、「証明者が受理される」ことと「証明者がウィットネスを知っている」ことが、数学的に等価な主張になる。抽出者の存在自体が、証明者の"知識"を操作的に定義する道具になっている点が重要である。

*(抽出者の具体的な構成技法 — 特にrewindingやforking lemma — は幕IIの第6回で、健全性増幅の議論とあわせて扱う。)*

## 4. ウィットネスの一般化:代数的関係から一般計算へ

ここからが今日の後半、そして幕I全体の締めくくりとなる話題である。

### 4.1 単純なウィットネス:構造に乗る証明

Schnorr識別プロトコルを考える。証明者は離散対数 $w$(群 $\mathbb{Z}_p^*$ の元)を知っており、$y = g^w$ を検証者に納得させたい。プロトコルの骨格は:

1. 証明者:ランダムな $r$ を選び、コミット $t = g^r$ を送る
2. 検証者:チャレンジ $c$ を送る
3. 証明者:レスポンス $s = r + cw$ を送る
4. 検証者:$g^s = t \cdot y^c$ を確認する

ここで本質的なのは、この検証等式 $g^s = t \cdot y^c$ が、**群の準同型性** $g^{r + cw} = g^r \cdot (g^w)^c$ から**直接**導かれているという点である。知識の抽出も同様に構造に依存する:2つの異なるチャレンジ $c_1 \ne c_2$ に対する応答 $s_1, s_2$ から、

$$w = \frac{s_1 - s_2}{c_1 - c_2}$$

という単純な線形代数で $w$ を直接復元できる(これをspecial 健全性と呼ぶ)。

**つまり、扱う関係の代数的構造が、そのままプロトコルの構造になっている。** 数学的対象(離散対数、平方剰余、etc.)が変われば、その都度手作りでプロトコルを設計できてしまう。

### 4.2 一般のウィットネス:構造がない場合

では、「このプログラムを実行した結果が $y$ になるような入力 $x$ を知っている」という関係だったらどうか。これは一般のNP関係であり、Circuit-SATに帰着できる(Cook-Levin定理)。計算は分岐・ループ・比較といった非代数的な操作の集まりであり、Schnorrプロトコルのように利用できる群の準同型性のような構造は、そもそも存在しない。

ここで生じる質的な転換を明確にしておきたい:

> 「群の準同型性を使う」から「**計算そのものを多項式の言語に翻訳する**」への発想の転換

この翻訳機構こそが**算術化(arithmetization)**であり、幕IIの中心的な話題(R1CS/QAP、AIR)として第4回に扱う。今日の時点では、この翻訳が**目的ではなく手段**であることを強調しておく。目的はあくまで、今日定義した完全性/健全性/ゼロ知識性を、任意の計算に対して満たすことである。

### 4.3 効率性の要求水準の変化

離散対数のような単純なウィットネスは固定長なので、証明サイズや検証コストがウィットネスに比例しても大きな問題にはならない。しかし計算が「任意の複雑さ」を持ちうるようになると、話が変わる。検証コストが計算量そのものに比例してしまっては、「検証者の負担を証明者に肩代わりさせる」というSNARK/STARKの存在意義そのものが失われる。

したがって、一般計算を扱うようになった瞬間から、**簡潔性(succinctness)**——証明サイズ・検証時間がウィットネスの複雑さに対してほぼ独立であること——が、あってもよい性質ではなく**必須要件**になる。ここで初めて、前回結果だけ提示したPCP定理やIOPの枠組みが、単なる理論的興味ではなく必然的な道具として要請されることになる(幕IIの第10回で技術的に扱う)。

### 4.4 知識の抽出の困難化

もう一点、構造の喪失が引き起こす技術的な困難さとして触れておきたいのが、抽出者の複雑化である。単純な代数的関係では、2つのtranscriptから線形代数で $w$ を直接復元できた。しかし一般の関係では、$w$ は回路全体を満たす割り当てであり、抽出には「木構造のtranscriptを辿る」といった、より精巧な技法(PLONKで使われるgeneralized special 健全性など)が必要になる。この技術的な困難さの増大自体が、単純な場合と一般の場合の質的な差を体現している。

## 5. 2軸マトリクスによる整理

以上の議論を、**表現力(ウィットネスの一般性)** と **効率性(対話性の除去・簡潔性)** という2つの独立した軸に整理する。

|                                  | 対話型・非簡潔            | 非対話・簡潔                               |
| -------------------------------- | ------------------------- | ------------------------------------------ |
| **代数的関係(単純ウィットネス)** | Schnorr, Chaum-Pedersen   | Σ-protocol + Fiat-Shamir(簡潔性はまだない) |
| **一般NP関係(任意の計算)**       | GMR型の一般ZK(理論的構成) | Groth16 / PLONK / STARK                    |

この表が伝えたいのは、**zk-SNARK/zk-STARKは単に「効率化されたプロトコル」なのではなく、表現力の軸と効率性の軸という2つの独立した進化を同時に達成した結果である**、ということである。幕IIではこの2つの軸それぞれを支える道具を並行して整備していくことになる。
