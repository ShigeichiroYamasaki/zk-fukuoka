## 自己チェック：どこを補えばよいか {#check}

1. `f(x) = x² + 1` のとき，`f(3)` と，`x = 0, 1, 2` に対する値の総和を求める．
2. 「すべての偶数は4の倍数である」を，反例一つで否定する．
3. 公平なコインを独立に3回投げ，すべて表になる確率を求める．
4. 行列 `[[1, 2], [3, 4]]` と列ベクトル `[2, 1]` の積を求める．
5. 秘密の値 `x` と公開値 `y` について `x² = y` を示したい．公開入力・ウィットネス・関係を分ける．
6. n個の要素を1回ずつ調べる処理と，すべての順序付きペアを調べる処理では，基本操作回数がどう変わるか．

::: details 答えと復習先
1. `f(3) = 10`，総和は `1 + 2 + 5 = 8`．式と多項式の評価を復習します．
2. 2は偶数ですが4の倍数ではありません．論理・全称命題・反例を復習します．
3. `1/8`．独立性を使って `1/2 × 1/2 × 1/2` と計算します．対話型証明の繰り返しでも常にそのまま掛け算できる，という意味ではありません（第6回）．
4. 列ベクトル `[4, 10]`．各行とベクトルの内積を計算します．
5. 公開入力は `y`，ウィットネスは `x`，関係は `x² = y`．さらに整数・有限体など，どの集合で計算するかを指定する必要があります．この整理だけでゼロ知識証明ができたわけではありません．
6. 前者はn回，後者はn²回（各要素の処理を定数時間とした場合）．入力サイズと計算量を復習します．
:::

## 有限体を手で計算する {#finite-field}

素数7を法とする有限体では，値を0から6で表します．7で割った余りを使って計算します．

```text
5 + 4 = 2  (mod 7)
3 × 5 = 1  (mod 7)
```

2番目の式から，3の乗法逆元は5です．0には乗法逆元がありません．法が合成数の場合は，0以外でも逆元を持たない元があります．たとえば法8では，2に何を掛けても余りは1になりません．これは有限体の導入例であり，ゼロ知識証明そのものではありません．

### 小さな演習

1. 法7で `6 + 6` と `4 × 5` を求める．
2. 法7で2の乗法逆元を求める．
3. 「秘密の値xが公開されたyを満たす」とき，公開入力・秘密入力・証明したい関係を分けて書く．

::: details 計算の答え
`6 + 6 = 5`，`4 × 5 = 6`．2の逆元は4（`2 × 4 = 1 mod 7`）です．3番目は自己チェック5を参照し，計算する集合と関係も指定してください．
:::
