# ホワイトペーパー

**ステータス：提案 · v0.1 · 2026年9月24日**

設立に向けた議論のための初期草案です。組織の設立完了やイベント開催の確定を示すものではありません。

## 目的

ZK Fukuoka は、ゼロ知識証明を理解し、実装できる技術者を育てる、福岡を拠点とするコミュニティの構想です。数学の理解と実装、相互レビュー、分かりやすい説明を結びつけます。

## 大切にすること

- 前提知識より好奇心：質問と失敗から学べる場をつくる。
- 手を動かす学び：輪読、演習、小さなプロジェクトを組み合わせる。
- 開かれた知識：教材と意思決定の記録を GitHub で管理し、日英で発信する。
- 適切な位置づけ：学習用の試作と、実運用できるシステムを区別する。

## 活動案

[シラバス](./learn/)を共通の学習経路として、勉強会、実装ワークショップ、成果発表を計画します。毎回の振り返りを次の活動に反映します。開催頻度、会場、講師、オンライン参加の方法は今後決定します。

## 運営案

まずはメンテナーと貢献者が Issue・Pull Request を通じて改善をレビューする形を想定します。重要な決定は、背景・代替案・影響とともに [ADR](./adr/) に記録します。役割分担、決定権限、運営ルールは今後合意する提案事項です。

## 目指す学習成果

証明の性質を説明できること、例題を再現できること、小さな回路を書けること、その限界を議論できることを重視します。再現性、つまずき、相互レビューの質を改善の手がかりにします。数値目標は未設定です。

## 今後決めること

初回の対象者・学習範囲・日程・ツール・行動規範・ライセンスを検討します。参加費、資金調達、連携先、認定制度は未定です。
