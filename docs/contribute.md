# 参加・貢献する

ZK Fukuoka は設立準備中です。開催日程、会場、参加申込はまだ公開していません。まずは GitHub で教材やコミュニティの構想づくりに関わることができます。

## できること

- **質問する：** 分からなかった箇所と試したことを Issue に書く。
- **教材を改善する：** 誤記の修正や再現できる例題を提案する。
- **翻訳する：** できる範囲で日本語版と英語版を一緒に更新する。
- **構想を議論する：** ホワイトペーパーや ADR に改善案を寄せる。

[Issue を作成する](https://github.com/ShigeichiroYamasaki/zk-fukuoka/issues/new) · [リポジトリを見る](https://github.com/ShigeichiroYamasaki/zk-fukuoka)

## 小さな貢献の流れ

1. [シラバス](./learn/)から対象のページを見つける。
2. 大きな変更は Issue で相談し、小さな修正はブランチを作成する。
3. `docs/` の Markdown と `docs/en/` の対応するページを編集する。
4. ローカルでビルドし、変更内容と確認したことを添えて Pull Request を作成する。

## 一緒に活動するために

異なる背景を尊重し、質問を歓迎し、建設的なフィードバックを心がけます。例題にはダミーデータを使用し、公開 Issue に個人情報や秘密情報を含めないでください。正式な行動規範とモデレーション体制は今後合意します。
