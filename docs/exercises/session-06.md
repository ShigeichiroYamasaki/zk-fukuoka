# 第6回の演習：FRIの折り畳みと健全性増幅

[第6回：Low-Degree Testingと健全性増幅](../learn/session-06) · [演習トップ](./)

次数を下げる折り畳みと，繰り返しによる健全性誤差を確かめる．

### やってみる

$f(X)=2+3X+X^2+2X^3$ を偶数次・奇数次に分け，$f(X)=f_e(X^2)+Xf_o(X^2)$ とする．$f_e(Y),f_o(Y)$ を求め，$\alpha=2$ のとき $f'(Y)=f_e(Y)+\alpha f_o(Y)$ を $\mathbb F_{11}$ で計算する．また，1回の誤差が $1/4$ の独立検査を3回繰り返すときの積を求める．

### 確認

$f_e=2+Y$，$f_o=3+2Y$，従って $f'=8+5Y$．次数は3から1へ下がる．誤差の積は $(1/4)^3=1/64$．繰り返しの解析には独立性または適切な条件付き誤差評価が必要．
