# 第12回の演習：PLONKのゲートとコピー制約

[第12回：PLONK](../learn/session-12) · [演習トップ](./)

PLONKのセレクタがゲート制約を選び，コピー制約が配線を守ることを確認する．

### やってみる

基本ゲート式 $q_La+q_Rb+q_Oc+q_Mab+q_C=0$ で，乗算 $3\cdot4=12$ を表すセレクタ値を一組書く．さらに二つのゲートで同じ値を使う例を作り，ゲート式だけでは値のコピーが保証されないことを示す．

### 確認

例えば $q_M=1,q_O=-1$，他は0とすれば $ab-c=0$ となる．各行の式が成立しても，別の行の入力欄が前の出力と同じ値かは独立には保証されないため，permutation argumentによるコピー制約が必要．
