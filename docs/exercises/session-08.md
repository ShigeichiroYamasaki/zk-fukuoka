# 第8回の演習：多項式コミットメント

[第8回：多項式コミットメントと暗号学的コミットメントの理論](../learn/session-08) · [演習トップ](./)

多項式の評価開示を商多項式と結び付ける．

### やってみる

$f(X)=X^2+2X+1$ とし，$x=3$ の評価 $y$ と $q(X)=(f(X)-y)/(X-x)$ を求める．因数定理を使い，KZGで商のコミットメントが開示証明になる理由を説明する．FRI/Merkle方式でMerkle経路と低次数検査が何を保証するかを区別する．

### 確認

$y=16$，$f(X)-16=(X-3)(X+5)$ なので $q=X+5$．Merkle経路は表の値がコミット済みであること，FRIは表が低次数多項式に近いことを検査する．
