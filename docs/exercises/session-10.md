# 第10回の演習：PCP・IOPの役割

[第10回：PCP定理とIOPの枠組み — 計算量理論的総括](../learn/session-10) · [演習トップ](./)

PCP・IP・IOPの検証者アクセスと，プロトコル構成要素の役割を分類する．

### やってみる

3方式を「対話回数」「各メッセージを読む範囲」で比較する．次に算術化，FRI，多項式コミットメント，Fiat–Shamirを，制約構成・近接性検査・問い合わせアクセスの実装・非対話化に割り当てる．

### 確認

PCPは証明を一度提示しランダムな少数箇所を読む．IPは複数ラウンドで各メッセージを読む．IOPは複数ラウンドでオラクル的な部分アクセスを行う．算術化は関係を制約化，FRIは低次数近接性を検査，コミットメントは値の固定と開示を実装，Fiat–Shamirはハッシュからチャレンジを導き非対話化する．
