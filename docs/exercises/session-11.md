# 第11回の演習：Groth16とQAP

[第11回：Groth16](../learn/session-11) · [演習トップ](./)

QAPの関係，Groth16の検証式，セットアップの役割を対応づける．

### やってみる

Groth16の検証式 $e(A,B)=e(\alpha,\beta)e(\mathrm{IC},\gamma)e(C,\delta)$ を見て，各項が公開入力や証明要素，セットアップ情報とどのように結び付くかを講義資料から対応づける．ペアリングの双線形性が，群要素として隠された値の関係を検査するのにどう役立つか説明する．次に，回路ごとのトラステッドセットアップで秘密にしておく値と，漏れると何が危険かを書く．

### 確認

ペアリングの双線形性で，証明要素どうしの指数の積をターゲット群内の積として比較する．$A,B,C$ は証明要素，$\mathrm{IC}$ は公開入力に対応する項，$\alpha,\beta,\gamma,\delta$ はセットアップで符号化された値に由来する．検証式はQAPとセットアップで生成された係数を組み込んだGroth16固有の関係であり，KZGの開示式やQAPの割り切れ性をそのまま一つのペアリングに置き換えたものではない．トラップドア漏洩は不正証明につながりうるため，セットアップ後に破棄または安全な分散生成を行う．
