# 第7回の演習：楕円曲線・ペアリング・仮定

[第7回：楕円曲線とペアリング](../learn/session-07) · [演習トップ](./)

ペアリングの双線形性を指数で確かめ，困難性仮定を区別する．

### やってみる

$P=g^a,Q=h^b$ に対し，$e(P,Q)$ を $e(g,h)$ の冪で表し，$a=3,b=4$ の指数を求めよ．さらに離散対数とq-SDHがそれぞれどの問題を困難と仮定するか，一文ずつ説明する．

### 確認

$e(g^a,h^b)=e(g,h)^{ab}$，例の指数は12（位数を法とする）．離散対数は $g,g^x$ から $x$ を求める問題，q-SDHは与えられたべき列から特定の逆数指数形式を作る問題で，別の仮定である．
