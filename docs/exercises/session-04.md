# # 第4回の演習：計算を制約へ翻訳する

[第4回：算術化の技法と計算量理論](../learn/session-04) · [演習トップ](./)

一つの計算が，R1CS・QAP・AIRでどう表されるかを段階ごとに確認する．

### やってみる

[入金と出金の算術化ページ](../learn/balance-arithmetization)で，入金 $(4,3)$，出金 $(2,5)$ の例を使う．R1CSの割当てで三つの残差が0になることを再計算し，QAPでは制約点 $1,2,3$ が消失多項式 $Z(X)$ の根になることを確かめる．最後にAIRのトレースで，初期値・更新・最終一致を指摘する．

### 確認

R1CSの割当ては $(1,4,3,2,5,7,7)$，各制約は成立する．$Z(X)=(X-1)(X-2)(X-3)$ は各制約点で0．AIRでは遷移だけでなく初期境界と最終境界も必要．詳細計算とPython実行はリンク先の演習を使う．
