# # 第3回の演習：有限体と確率的検査

[第3回：有限体・多項式の代数と確率的検査](../learn/session-03) · [演習トップ](./)

有限体の計算とSchwartz–Zippel補題の誤り確率を確かめる．

### やってみる

$\mathbb F_7$ で $2/5$ を計算せよ．さらに $h(X)=X(X-1)$ を $S=\{0,1,2,3,4,5,6\}$ から一様に選んだ点で検査するとき，$h(r)=0$ となる確率を求めよ．$|S|=4$ の集合 $\{0,1,2,3\}$ でも計算し，補題の上界と比べよ．

### 確認

$5^{-1}=3$ なので $2/5=6$ in $\mathbb F_7$．全体では根が2個なので確率 $2/7$，上界は $2/7$．小集合では確率 $2/4=1/2$，上界は $2/4=1/2$．$S$ が小さいほど誤り確率の上界が大きくなる．
