# 第15回の演習：再帰・folding・応用の研究地図

[第15回：発展の方向性](../learn/session-15) · [演習トップ](./)

再帰的証明，folding，GKR/sumcheckが改善する対象を区別し，Ethereum応用の状況を資料から読み取る．

### やってみる

1. 「前の証明を次の証明内で検証する」と「二つの緩和R1CSインスタンスをfoldする」の違いを説明する．
2. $g(x,y)=x+y$ について $x,y\in\{0,1\}$ の総和を求める．sumcheckの最初の一変数に対する多項式 $h(X)=\sum_{y\in\{0,1\}}g(X,y)$ を計算し，検証者が行う最初の整合性チェックを書く．
3. [EIP-8025の公式提案](https://eips.ethereum.org/EIPS/eip-8025)でステータスと，提案が現行仕様で実行再実行を廃止するかを確認する．

### 確認

再帰的証明は証明検証自体を別の証明で包み，foldingはインスタンスを軽量に集約して最後に証明する．総和は4，$h(X)=2X+1$ で $h(0)+h(1)=1+3=4$．講義資料の2026年9月29日時点の確認ではEIP-8025はDraftで，実行証明は任意の補助検査，payloadの再実行を置き換えない．ステータスは変化しうるため，演習時は公式提案ページを再確認する．
