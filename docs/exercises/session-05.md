# # 第5回の演習：Reed–Solomon符号の距離

[第5回：誤り訂正符号と情報理論的視点](../learn/session-05) · [演習トップ](./)

RS符号語を実際に計算し，距離から訂正能力を導く．

### やってみる

$\mathbb F_7$ 上で評価点を $0,1,2,3,4$，次数 $<2$ とする．$f(X)=2X+1$ と $g(X)=1$ の符号語を計算し，ハミング距離，最小距離，一意訂正可能な誤り数を求める．

### 確認

$f$ の符号語は $(1,3,5,0,2)$，$g$ は $(1,1,1,1,1)$．距離は4．ここでは $n=5,k=2$ なので $d_{\min}=n-k+1=4$，一意訂正数は $\lfloor(4-1)/2\rfloor=1$．
