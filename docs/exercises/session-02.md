# # 第2回の演習：シミュレーションと識別

[第2回：ゼロ知識性とウィットネスの一般化](../learn/session-02) · [演習トップ](./)

識別者の判定差を数値で求め，ゼロ知識性の比較対象を整理する．

### やってみる

二つの分布 $P_0,P_1$ が，ビット列 $00,11$ と $01,10$ をそれぞれ確率 $1/2$ で出すとする．「二ビットが等しければ1」と出力する識別者の出力確率と識別差を求める．次に，Schnorr識別の公開値を $y=g^x$ とし，ウィットネスが何かを書く．

### 確認

$P_0$ で出力1の確率は1，$P_1$ では0なので識別差は1．Schnorrでは言明が「公開値 $y$ が生成元 $g$ の冪で，離散対数を知る」，ウィットネスは $x$ であり，関係は $g^x=y$．
