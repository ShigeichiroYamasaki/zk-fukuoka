# 第2回の演習：ゼロ知識性とウィットネスの一般化

[第2回：ゼロ知識性とウィットネスの一般化](../learn/session-02) · [演習トップ](./)

講義で扱った五つの考え方――確率分布によるゼロ知識性，グラフ同型性プロトコル，知識の健全性と抽出器，Schnorrの代数的構造，表現力と効率性――を一つの流れとして確かめる．各課題に答えたあと，「何を検査しているのか」「どの情報が誰に見えるのか」を自分の言葉で説明しよう．

## 1. 関係 $R$ とゼロ知識性の比較対象

### 課題

1. 関係 $R$，公開入力 $x$，ウィットネス $w$ を使って，「$x$ が関係に属するウィットネスを持つ」という命題を表せ．
2. ゼロ知識性で比較する実際の検証者の記録 $X$ とシミュレータの出力 $Y$ を，それぞれ何から生じる確率変数として定義するか説明する．シミュレータにウィットネスを渡すかどうかも答えよ．
3. 完全ゼロ知識，統計的ゼロ知識，計算量的ゼロ知識の違いを説明する．
4. 正直な検証者に対するゼロ知識性（HVZK）と，任意の検証者に対するゼロ知識性を区別する．
5. 講義の二ビット例を使う．$P_0$ は $00,11$ をそれぞれ確率 $1/2$ で出し，$P_1$ は $01,10$ をそれぞれ確率 $1/2$ で出す．各ビットだけを見た周辺確率は一致することを確かめたうえで，「二ビットが等しければ1」を出力する識別者の出力確率と識別差を求める．
6. 別の例として，$P(00)=P(01)=1/2$，$Q(00)=Q(10)=1/2$ とする．識別者 $D$ が「先頭ビットが0なら1」を出力するときの識別差を求めよ．この二つの分布の統計距離も求めよ．

### 解答例・自己確認

関係 $R$ は公開入力とウィットネスの組の集合であり，命題は

$$x\in L_R\quad\Longleftrightarrow\quad \exists w\;(x,w)\in R$$

と表せる．実際のやり取りで検証者が観測する記録全体を，証明者と検証者の乱数を選び直すたびに変わる確率変数 $X$ とする．シミュレータは公開入力などを受け取って独自の乱数で記録を出力し，その出力を確率変数 $Y$ とする．シミュレータにはウィットネス $w$ を渡さない．固定した同じ公開入力（必要なら補助入力も固定する）に対し，$X$ と $Y$ の記録の確率分布を比べる．

完全ゼロ知識は確率分布が完全に一致すること，統計的ゼロ知識は分布間の統計距離が無視できるほど小さいこと，計算量的ゼロ知識は多項式時間の識別者が見分ける確率差が無視できるほど小さいことを要求する．HVZKは，プロトコルで指定されたとおりに動く正直な検証者の記録をシミュレータが再現する性質である．任意の検証者に対するゼロ知識性では，チャレンジの選び方を変える検証者なども対象にするため，HVZKだけで自動的に保証されるわけではない．

二ビット例では，各位置の0・1の確率はいずれも $1/2$ だが，同じビットかどうかは異なる．等しいとき1を出す識別者は $P_0$ で確率1，$P_1$ で確率0を出すため，識別差は1である．二つ目では，$D$ が1を出す確率は $P$ で1，$Q$ で $1/2$ なので差は $1/2$ である．二つの分布は $00$ に確率 $1/2$ を共有し，残る確率質量が $01$ と $10$ に分かれるため，統計距離も $1/2$ である．この例は，識別者が見つける差が統計距離を下回らないことを確かめる小さな例である．

## 2. グラフ同型性プロトコルを一回ずつ追う

第1回のグラフを使う．$G_0$ の頂点は $\{a,b,c,d\}$，辺は $\{ab,bc,ca,cd\}$．$G_1$ の頂点は $\{1,2,3,4\}$，辺は $\{12,23,31,14\}$ とし，同型写像を

$$\pi(a)=2,\quad\pi(b)=3,\quad\pi(c)=1,\quad\pi(d)=4$$

とする．

### 課題

1. 証明者がランダムな頂点置換 $\rho$ で $H=\rho(G_0)$ を作り，先に $H$ を送る．その後に検証者が $b\in\{0,1\}$ を選ぶとき，それぞれのチャレンジに対する有効な返答写像を答えよ．
2. 検証者が受け取った写像 $f:G_b\to H$ を検査する条件を二つ書けるか．「辺が保たれる」だけで十分かも考える．
3. $G_0,G_1$ が同型である場合の完全性を説明する．
4. 二つのグラフが同型でない場合，同じコミット済みの $H$ について証明者が正しく答えられるチャレンジは高々いくつか．1回の受理確率と，独立なチャレンジを $k$ 回繰り返したときの受理確率の上限を求めよ．

### 解答例・自己確認

$b=0$ への返答は $\rho:G_0\to H$ である．$b=1$ では $\pi^{-1}:G_1\to G_0$ の後に $\rho$ を適用し，$\rho\circ\pi^{-1}:G_1\to H$ を返す．検証者は，(i) $f$ が全頂点を重複なく対応づける全単射であること，(ii) 任意の頂点対について辺であることと辺でないことの両方が保たれることを確かめる．辺だけを確認すると，非辺を辺に写す誤った対応を見逃す可能性がある．

二つのグラフが同型なら，秘密の $\pi$ を使ってどちらのチャレンジにも正しく答えられるので，正直な証明者は受理される．同型でなければ，一つの $H$ が両方と同型になることはなく，固定した $H$ に対して正しく答えられるチャレンジは高々一方である．検証者のチャレンジは一様な1ビットなので，1回の誤受理確率は高々 $1/2$，独立に $k$ 回繰り返して全て通る確率は高々 $2^{-k}$ である．

## 3. シミュレータと抽出器を区別する

### 課題

1. グラフ同型性の正直な検証者に対するシミュレータは，ウィットネス $\pi$ なしでどのように記録を生成できるか，生成順を含めて説明する．
2. 「記録を生成できること」と「実際の対話でどのチャレンジにも答えられること」が同じではない理由を説明する．
3. 同じ $H$ について，抽出器が二つの受理応答 $f_0:G_0\to H$ と $f_1:G_1\to H$ を得たとする．$G_0\to G_1$ のウィットネスを構成し，なぜ有効か説明する．
4. シミュレータと抽出器について，入力・利用する相手・出力・目的を表にして比較する．証明者の内部メモリを直接読む必要があるかも記す．
5. 証明者の受理確率を $p$，知識誤差を $\kappa$ とする．差 $\delta=p-\kappa$ は何を表すか．受理確率と抽出成功確率を同じものとして扱えないのはなぜか．

### 解答例・自己確認

正直な検証者に対するシミュレータは，まずランダムなチャレンジ $b$ を選び，$G_b$ のランダムな頂点付け替え $H=\varphi_b(G_b)$ を作り，対応表 $\varphi_b$ とともに記録を出力できる．$G_0$ と $G_1$ が同型なら，どちらからランダムに付け替えても同じ分布の $H$ が得られるため，実際の対話記録と一致する．実際の対話では証明者が先に $H$ を固定してからチャレンジを受けるが，記録を作るシミュレータは出力全体の分布が合うように生成順を逆にできる．記録の模倣は，ライブの対話で後から来るチャレンジに答える能力を意味しない．

二つの応答から

$$\pi'=f_1^{-1}\circ f_0:G_0\to G_1$$

を作る．$f_0$ は $G_0$ から $H$ へ，$f_1^{-1}$ は $H$ から $G_1$ への同型写像なので，合成も辺と非辺を保つ同型写像である．抽出器は証明者を所定の方法で実行・巻き戻して返答から有効なウィットネスを構成する仮想アルゴリズムであり，内部メモリを覗く存在ではない．一方，シミュレータはウィットネスを使わず検証者の記録を生成する．両者はアクセス方法も目的も出力も異なる．知識の健全性では，受理確率 $p$ が知識誤差 $\kappa$ をどれだけ上回るか，すなわち $\delta=p-\kappa$ と，抽出器の計算時間・抽出成功確率を結び付ける．$p$ は通常の対話で受理される確率，抽出成功確率は抽出器が別のアクセス実験で有効なウィットネスを出せる確率であり，同じ確率変数ではない．具体的な保証の形は方式と定義に依存する．

## 4. Schnorrの代数的な検証とウィットネスの抽出

位数 $q=11$ の群で $p=23$，$g=2$，秘密指数 $w=3$ とする．公開値は $y=g^w\bmod p=8$ である．証明者は $r=4$ を選び，コミットメント $t=g^r\bmod p=16$ を送る．応答式は $s=r+cw\pmod q$，検証式は $g^s\equiv t y^c\pmod p$ である．

### 課題

1. チャレンジ $c_1=2$ の応答 $s_1$ を求め，検証式の左右を計算する．
2. 同じ $t$ について，別のチャレンジ $c_2=5$ と応答 $s_2=8$ を使い，検証式が成立することを確かめる．
3. 二つの受理記録から $w'$ を計算する式を導き，値を求める．$w'$ がウィットネスであることを確認する．
4. この抽出で同じコミット $t$ と異なるチャレンジが必要な理由を説明する．この操作を通常の検証者が行うべきだという意味かどうかも答える．

### 解答例・自己確認

$$s_1=4+2\cdot3=10\pmod{11}.$$

検証式の左辺は $2^{10}\bmod23=12$，右辺は $16\cdot8^2\bmod23=12$ で一致する．二つ目は $2^8\bmod23=3$，$16\cdot8^5\bmod23=3$ である．同じ $t$ に対する受理式から

$$s_1-s_2\equiv (c_1-c_2)w\pmod q$$

となるため，$c_1\ne c_2$ なら

$$w'=(s_1-s_2)(c_1-c_2)^{-1}\pmod{11}=3.$$

$2^3\bmod23=8=y$ なので有効なウィットネスである．同じ $t$ を使うことで，二つの式からコミット前の乱数 $r$ に由来する項が消える．異なるチャレンジの差は $q$ を法として逆元を持つ．これは安全性証明で抽出器が証明者を巻き戻す説明であり，通常の検証者が二度チャレンジを送る手順ではない．

## 5. 一般計算への拡張と二つの評価軸

### 課題

1. Schnorrの例ではウィットネスが指数 $w$ であり，群の式 $y=g^w$ が検証に使えた．任意のプログラムの正しい実行を証明する場合，ウィットネスが何になりうるか，なぜ同じ検証式をそのまま使えないかを書く．
2. 算術化がこの問題に対して果たす役割を一文で述べる．算術化そのものがゼロ知識証明かどうかも答える．
3. 表現力と効率性の二軸で，Schnorr，Fiat–Shamir後のSchnorr型方式，Groth16／PLONK／STARKを講義の表に沿って位置づける．
4. 次の三つの性質を混同していないか，それぞれ別の問いとして説明する：ゼロ知識性，非対話性，簡潔性．Fiat–Shamir変換だけで証明が短くなるかも答える．

### 解答例・自己確認

一般の計算では，ウィットネスは計算を実行した入力や中間状態など，制約を満たす計算の記録になりうる．Schnorrのように全ての計算へ共通に使える単純な群の等式があるとは限らない．算術化は，計算の正しさを回路や多項式制約など，証明方式が検査できる形に翻訳する準備であり，それ自体は証明でもゼロ知識性の保証でもない．

Schnorrは特定の代数的関係を対話で確かめる方式である．Fiat–Shamir変換を適切な条件のもとで使うと対話を省けるが，それだけで一般計算に対する簡潔性を得るわけではない．Groth16，PLONK，STARKは一般計算に対する簡潔な証明方式の例として講義で扱う．

ゼロ知識性はウィットネスの情報が漏れないか，非対話性は証明者とリアルタイムに往復せず検証できるか，簡潔性は大きな計算に比べて証明と検証の負担を抑えられるかを問う．これらは別々の性質であり，セットアップ費用や証明者の計算量も独立に評価する．
