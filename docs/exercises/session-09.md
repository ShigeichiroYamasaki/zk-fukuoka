# 第9回の演習：Fiat–Shamir変換とROM

更新日：2026年10月18日

[第9回：Fiat-Shamir変換とROMの功罪](../learn/session-09) · [演習トップ](./)

Fiat–Shamir化で暗号学的ハッシュ関数に与える入力とROMの限界を確認する．

### やってみる

Schnorr型プロトコルで証明者がコミットメント $a$ を送った後にチャレンジ $c$ を受け取る．Fiat–Shamir化で暗号学的ハッシュ関数に含めるべき内容と，最終検証に使う記録を列挙する．具体的な暗号学的ハッシュ関数への置換をROM証明だけで保証できない理由も述べる．

### 確認

少なくともプロトコル識別子，公開入力で定まる命題，コミットメントを束ねる（実際は先行transcript全体を含める）．記録には公開入力，コミットメント，導出チャレンジ，応答が含まれる．ROMは理想的ランダム関数のモデルであり，SHA等の具体的な暗号学的ハッシュ関数を直接証明しない．
