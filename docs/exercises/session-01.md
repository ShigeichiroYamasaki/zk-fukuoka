# # 第1回の演習：証明の言明と検査

[第1回：証明とは何か](../learn/session-01) · [演習トップ](./)

公開言明 $x\in L$ とウィットネス $w$ の関係を，具体例で確認する．

### やってみる

言語 $L$ を「辺数が同じ二つのグラフが同型である」という言明の集合とする．小さなグラフを一組選び，頂点の置換 $\pi$ がウィットネスになる条件を，隣接関係を使って書け．その置換が全単射であることも確認する．

### 確認

言明は公開される二つのグラフについての性質で，ウィットネスは同型を示す頂点対応である．置換を検証するには，全ての頂点対の隣接関係が保存されることを確かめる．
