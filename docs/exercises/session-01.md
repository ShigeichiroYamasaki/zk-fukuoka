# 第1回の演習：証明とは何か

[第1回：証明とは何か](../learn/session-01) · [演習トップ](./)

この演習では，NP検証者の考え方から対話型証明系の形式的な性質までをつなげて確認する．計算量理論の定理を証明するのではなく，何を表し，何を保証するのかを説明できることを目標にする．

## 1. 言語・命題・ウィットネスを区別する

### 課題

「合成数の符号化全体」を言語 $L_{\mathrm{comp}}$ とする．入力 $x=91$ について，次を埋めよ．

1. 命題 $x\in L_{\mathrm{comp}}$ の意味を書く．
2. ウィットネス $w$ と検証アルゴリズム $V(x,w)$ の条件を書く．
3. $w=7,13,8,1$ のそれぞれで受理・拒否を判定し，理由を書く．
4. 「91が合成数である」という命題と，ウィットネス7を区別して説明する．
5. 検証時間を整数値 $x$ ではなく符号化長 $|x|$ に対して測る理由を，二進表記に触れて説明する．

### 解答例・自己確認

`$x\in L_{\mathrm{comp}}$` は「符号化された整数 $x$ が合成数である」という命題である．一つの検証方法は，ウィットネスを約数 $w$ とし，$1<w<x$ かつ $w$ が $x$ を割り切ることを確認することである．形式的には

$$x\in L_{\mathrm{comp}}\iff \exists w\;(1<w<x\;\land\;x\bmod w=0).$$

91では7と13が受理される．8は91を割り切らず，1は範囲条件を満たさないため拒否される．命題は確認したい性質，ウィットネスはその性質を検査するための具体的な情報であり，同じ命題に複数のウィットネスがありうる．

計算量は入力の符号化長で測る．二進表記の長さが $n$ の整数は最大でおよそ $2^n$ の大きさになりうるため，数値そのものに対する多項式時間と，入力長に対する多項式時間は同じ意味ではない．

## 2. グラフ同型性をウィットネスで検査する

### 課題

次の二つの無向単純グラフを考える．

- $G_0$ の頂点は $\{a,b,c,d\}$，辺は $\{ab,bc,ca,cd\}$．
- $G_1$ の頂点は $\{1,2,3,4\}$，辺は $\{12,23,31,14\}$．

1. 写像 $\pi(a)=2,\pi(b)=3,\pi(c)=1,\pi(d)=4$ が全単射であることを確認する．
2. $G_0$ の各辺が $G_1$ の辺に写ることを表にする．
3. 辺でない頂点対も保たれることを確認する．
4. 「頂点数と辺数が等しい」だけでは同型性を示せないことを，頂点5個・辺3本の反例二つで説明する．

### 解答例・自己確認

写像の像は $\{1,2,3,4\}$ を重複なく一度ずつ含むため，全単射である．辺の対応は $ab\mapsto23$，$bc\mapsto31$，$ca\mapsto12$，$cd\mapsto14$ で，いずれも $G_1$ の辺である．非辺の頂点対は $ad,bd$ であり，それぞれ $24,34$ に写る．どちらも $G_1$ の非辺なので，写像は辺と非辺の両方を保ち，同型写像である．

反例として，5頂点の星グラフ $K_{1,3}$ に孤立頂点を加えたグラフと，4頂点の道 $P_4$ に孤立頂点を加えたグラフを考える．どちらも辺は3本，頂点は5個だが，次数の並びは前者が $(3,1,1,1,0)$，後者が $(2,2,1,1,0)$ で異なる．次数は同型写像で保たれるため，二つは同型ではない．

## 3. NP検証者から対話型証明へ

### 課題

次の問いに答えよ．

1. NP検証者の式 $x\in L\iff\exists w\;V(x,w)=1$ において，証明者と検証者が実際に何をするかを説明する．
2. 講義で整理した二つの前提（ウィットネス全体を見せること，一方向の一回の読み取り）をそれぞれ書き，何を問い直すとゼロ知識性・対話型証明の動機につながるか対応づける．
3. Arthur–Merlin型の対話で，ランダムな質問を証明者の返答より前に出すことがなぜ重要か説明する．単にメッセージを細かく分けて送ることとの違いも述べる．
4. IP = PSPACE が示すことを一文で述べ，この定理だけからは結論できないことを一つ挙げる．
5. パスワード認証とグラフ同型性の例で，検証者が知りたいことと，証明者が明かしたくない情報をそれぞれ挙げる．

### 解答例・自己確認

NP検証者では，証明者がウィットネスを提示し，検証者は入力とウィットネスから受理・拒否を決める．全開示性を問い直すと「秘密を渡さずに納得させられるか」というゼロ知識性の動機になる．一方向性を問い直すと「検証者の質問と証明者の応答を許すと検証能力が変わるか」という対話型証明の動機になる．

質問が返答に応じて選ばれると，証明者はその質問に合わせて応答することになる．一方的に分割したメッセージを送るだけでは，検証者のランダムな質問に応じて応答を変える相互作用は生じない．IP = PSPACE は，多項式時間の確率的検証者と対話する証明系で判定できる言語のクラスがPSPACEに一致するという結果である．これは $\mathrm{NP}=\mathrm{PSPACE}$ や $\mathrm{P}=\mathrm{PSPACE}$ を意味しない．パスワード認証で確認したいのは相手が秘密を知っていることだが，パスワードそのものを渡すと検証者にも秘密が伝わる．グラフ同型性では，同型写像があれば命題を直接確かめられる一方，その写像自体を明かさずに納得させたいという動機がある．

## 4. 完全性・健全性・Proof・Argument

### 課題

各方式や検証者について，満たす性質・満たさない性質を判定し，理由を書く．

1. 真の命題に対し，正直な証明者との対話を高確率で受理する．
2. 偽の命題に対し，どの不正な証明者も受理させられない（要求された誤り上限の範囲内）．
3. 何でも受理する検証者．
4. 何でも拒否する検証者．
5. Proof と Argument の違いを，不正な証明者に許す計算時間を使って説明する．

### 解答例・自己確認

1は完全性，2は健全性の条件である．3は真の命題を受理するので完全性は満たしうるが，偽の命題も受理するため健全性を満たさない．4は偽の命題を受理しないので健全性は満たしうるが，真の命題も拒否するため完全性を満たさない．

Proofでは健全性を破ろうとする証明者の計算時間を制限しない．Argumentでは不正な証明者を多項式時間に制限し，その範囲で健全性を保証する．検証者の効率性ではなく，不正な証明者に認める能力の違いである．
